■ 論考の前提・証明の定義・方法論について
（日本語完全版の巻末付録 pp.68–69 の同じ題の節と同文）

あらゆる科学や哲学も、目指すところは完成された論理（説明）モデルの獲得であり、それはつまり「完全に閉じた論理」である。また「客観的事実」や「既存の科学の作法」というものも、本書と同じく一つの「便宜」に従い、主観に基づき扱われるものである。したがって、探求において本来行われるべき作業は、反証にも至らない終わりのない懐疑ではなく、閉じた論理に到達することである。

本書における「証明」とは、数式や専門用語を用いる狭義の数学的・演繹的証明ではなく、この閉じた論理の中で、個人や世界の存在が疑問を残さず確かに成り立つという「状態」を日常の言葉だけで明らかにし、確定させることである。もっとも、非常に平易で身近な概念のみを最小限の公理（前提）として敷き、外部の仮定を持ち込まずに論を組み立てて世界と個人の実在を導き出しているという構造そのものに着目すれば、広義には公理系に基づく演繹的な証明と同じ手続きを踏んでおり、文字通り『世界の証明』として成立している。もし仮にいつか、科学が宇宙の謎を演繹的作法で解き明かしたとしても、「それは果たして根本的な説明になっているのか？」という問いは残るが、本書はその段階での論考を行なっているのである。

また、第1章・第2章（主観による枠組みと、「そう思う」という感覚としての観念の定義）から第3章（「あらゆる存在は観念そのものである」という仮説）への展開に「認識論から存在論への飛躍がある」という指摘も当てはまらない。なぜなら、「観念の外側に独立した客観的物質が存在するかもしれない」という想定や推測自体が、第1章・第3章で示した通り「観念（そう思う）の働き」によってもたらされた一つの枠組みであり、そこで想定される物質も、観念（意識）と同等の存在であると考えることができるからである。したがって、第1章〜第3章の前提に立った時点で「認識（主観）」と「外的な存在」の間に原理的な上下・主従の隔たりはない（私たちと世界は同等の存在である）。本書は第3章でそれを「仮説」として置いた上で、第4章〜第6章で時間や無の疑問がすべて矛盾なく解けることを検証し、終章で結論として回収することで飛躍なく論を閉じている。

その上で本書は、説明になってさえいれば答えは何通りあってもいいとしている。根本の前提に対する反証ができないのは、それを求める側も同じである。前提や論を受け入れるかは個人の自由であるが、一つの完結した説明として閉じているものに対し、部分的な切り取りによって懐疑を行うだけでは反証にはならない。時間や存在などに対して既存の定義付けだけを外部から当てはめようとすることも同様であり、論理的な批判としては成立しない。火を使わない料理はあるし、カレーライスにパスタを入れる必要はない。車に乗りながら自転車に乗ることはできないように、自らの前提の反証可能性を問わずに、別の体系の要素を当てはめるべきではないのである。

すなわち、本論考のような閉じた公理系（論理モデル）を検証する際の唯一の論理的作業とは、「提示された入り口（最小限の前提）に立ったとき、出口まで矛盾なく閉じているか」を確認することだけである。入り口に入ることを拒み、外部から無関係な要素や別の物差しを並べて批判を試みることは、対象のモデルの検証ではなく、単に「別の前提体系から別の話をしている」ことになる。そもそも本論考は、他者と正しさを競い合ったり誰かを論破したりするためではなく、「正しさの押し付けや虚無から、人間それぞれが大切にしている世界（境界）と個人の存在を守る」という目的のために構築された論理構造である。したがって、この構造が「個人と世界の実在を矛盾なく証明し、守り切る仕組みとして完結しているか」という本筋を離れ、外部の基準で否定しようとすることは、別体系の規則の持ち込みにあたり、本書の内部論理に対する批評としては噛み合わないのである。

■ 本論理式の適用範囲に関する3つの免責事項と証明の二層構造

1. 数式による世界の還元を目的としたものではない 本書の本質は、平易な日常言語によって個人と世界の実在およびその境界を守り切ることにあり、本ページの論理式が「数式そのものとして世界のすべてを説明している」と主張するものではない。あくまで、本文の主要な主張を前提と結論に分けて書き直し、結論が前提から矛盾なく導かれることを検算するための補助ツールである（本文の推論の一つ一つを検算するものではない）。
2. 外部前提（主客二元論・直線的時間モデル）を置かない 本モデルは、標準的な（古典）一階論理に文演算子 $\mathbf{S}$・$F$・$Truth$ を加えた言語を用いるが（扱いは第Ⅰ節【1】(4)）、「認識の外部に客観的個体があらかじめ存在する」「時間は数直線上の前後関係である」といった外部の前提は、公理として置かない。置くのは、本書の内部規則（枠組みの便宜化、観念の根源性、相互成立の対称性、単一座標の連続性）を写した定義と公理だけである。
3. 検証の範囲（①定理の導出可能性と②公理系の無矛盾性の区別） 数理論理学において「定理T1〜T8の導出可能性」と「公理系の無矛盾性」は別個の証明課題であるため、本仕様書では以下の2つを別々に示す。
  • 検証対象①：T1〜T8の導出可能性（Syntactic Derivability）
    第Ⅳ節において、型付けされた形式言語 $\mathcal{L}$ 内で、定義 D1〜D5 と公理（図式を含む）A1, A2, A4〜A8 から推論規則のみで各定理を導出する（$\text{D1–D5}, \text{A1, A2, A4–A8} \vdash \text{T1–T8}$）。
  • 検証対象②：公理系の無矛盾性（Semantic Consistency）
    第Ⅵ節において、定義と公理の全19式を同時に真にするモデル $\mathcal{M}$ を構成し検算する（$\mathcal{M} \models \text{D1–D5} \cup \{\text{A1, A2, A4–A8}\} \implies \text{無矛盾}$）。

■ 証明の二層構造

本書における「証明」は、上の節に書いたとおり、日常の言葉による広義のものであり、本データはそれを狭義の数学的証明に置き換えるものではない。本データが示すのは、本書の論を形式言語で組み直した体系について、次の2点が狭義に（数理論理学の意味で）成り立つことである。
  • 定義と公理から、定理 T1〜T8 が導かれること（第Ⅳ節）
  • その定義と公理が、互いに矛盾しないこと（第Ⅵ節）
前提（公理）そのものが正しいことを示すものではない。

Ⅰ. 形式言語 ℒ の型付け（存在ソート・座標ソートと文演算子）および原始記号

「一階述語論理の量化」と「命題（論理式）に対する操作」の混在を排除し、あわせて「存在」と「座標（位置）」を取り違えないために、本体系の形式言語 $\mathcal{L}$ の型（ソート）と構文規則を以下のように定める。

【1. 形式言語 ℒ の型付け】

  1. 存在ソート（Entity Sort, $\text{Ent}$）：
    量化子（$\forall, \exists$）が走る、存在（個体）の領域 $D_E$ に属する項の集合。
    • 存在の変数：$x, y, a$
    • 存在の定数：$S_{\text{ind}}$（個人の個別観念）、$World$（世界全体）
    • （※ Rev. 4 の変数 $S_x$（任意の観念個体）は、述語 $S$・演算子 $\mathbf{S}$ との混同を避けるため、存在の変数 $y$ に改めた。）
  2. 座標ソート（Coordinate Sort, $\text{Crd}$）：
    量化子が走る、座標（位置）の領域 $D_C$ に属する項の集合。座標は存在の一つではなく、存在の「位置」を表すための型である（本文 p.47「座標で例えるなら、あらゆる現象は、同一座標点上で展開されていると考えればイメージしやすい」）。
    • 座標の変数：$c, c'$
    • 座標の定数：$c_0$（唯一の原理的座標）
    • 関数記号：$Loc: \text{Ent} \to \text{Crd}$（存在 $t$ に対し、その位置する座標 $Loc(t)$ を返す）
  3. 述語記号：
    • 存在についての単項述語：$S, B, PE, Concept, M, Ext_{\text{原理的}}, Gen, Begin, End, \text{AlreadyPresent}, \text{AbsoluteNothing}, \text{Limited}$
    • 存在についての二項述語：$P(t_1, t_2), \text{CoPresent}(t_1, t_2), \text{Same}(t_1, t_2)$
    • 座標についての二項述語：$C(c_1, c_2)$（連続性）、$\text{Before}(c_1, c_2)$（前後）
    • 等号：存在どうし、座標どうしについて $t_1 = t_2$
  4. 論理式（$\text{WFF}_{\mathcal{L}}$）と文演算子：
    原子論理式から、論理結合子（$\neg, \land, \lor, \implies, \iff$）、存在・座標の変数に対する量化（$\forall, \exists$）、および文演算子 $\mathbf{S}(\phi), F(\phi), Truth(\phi)$（$\phi \in \text{WFF}_{\mathcal{L}}$）によって帰納的に作られる論理式の集合。
    • 命題（論理式）そのものは量化しない（命題は領域の要素ではなく、ソートでもない）。$\phi$ を含む規則（A1, A2, A8, D5a）は、任意の論理式 $\phi$ を当てはめた一つ一つを公理とする「公理図式」である（A8 では、$x$ を自由変数として含む任意の論理式 $\phi(x)$）。
    • 文演算子の扱い：$\mathbf{S}(\phi)$・$F(\phi)$・$Truth(\phi)$ は、論理式 $\phi$ ごとに、$\phi$ の自由変数を引数とする一つの述語として扱う（例えば $\mathbf{S}(B(x))$ は、$x$ についての一項述語である）。したがって本体系は通常の（多ソートの）一階論理の言語であり、健全性定理がそのまま使える。文演算子の中では、論理的に同値な別の式への置き換えはしない（定義された記号を定義の右辺に展開することは、同じ式の書き換えなので、してよい）。

Ⅱ. 定義（Definitions: D1〜D5）

本文および付録において語の意味を規定する内部規則。各記号は一度だけ定義する。定義された記号は略記であり、どの式の中でも（文演算子 $\mathbf{S}, F, Truth$ の中でも）定義の右辺に置き換えて読む。したがって定義は新しい主張を足さない（主張を足す式は、第Ⅲ節の公理として置く）。

D1（観念の定義） 本文 第2章 p.37–38・第3章 p.40

理解・納得・認識・措定など、何かが「在る」として成立する働きはすべて「そう思う」という観念の成立 $\mathbf{S}$ である。便宜的分割を介さない原理的領域において、$x$ が観念 $S(x)$ であるとは、「$x$ が存在する」ということが観念 $\mathbf{S}(B(x))$ として成立していることである。（※ Rev. 4 の D1b・D1c は、新しい主張を含むため、定義ではなく公理 A7・A8 とした。）

D1 :  ∀x  ( S(x) ⇔ 𝐒(B(x)) )
【読み方】$x$ が観念であることと、「$x$ が存在する」と観念されることは同値である。
[LaTeX] $$\text{D1}: \quad \forall x \, (S(x) \iff \mathbf{S}(B(x)))$$
D2（便宜的枠組みと外部・一方的生成・境界の定義） 本文 第1章 p.32–34・第5章 p.45・第6章 p.49・終章 p.52・前文・詩「境界」

「主観と客観」「精神と物質」「過去・現在・未来（時系列 $F_{\text{time}}$）」および「自他の境界」は、観念の内部で設定された構造上の分割規則（便宜 $F$）である（※この前置きは本文の背景の説明であり、D2a〜D2e の式には $F$ は現れない。$F_{\text{time}}$ は記号ではなく、「時系列という便宜」の呼び名である）。これに基づき、本体系において棄却対象となる「原理的外部（$Ext_{\text{原理的}}$）」「一方的生成（$Gen$）」「時間的境界（$Begin, End$）」「絶対的無（$\text{AbsoluteNothing}$）」を以下の論理式で定義する。（※ D2a は自己言及を含まない単項形 $\forall x \, (Ext_{\text{原理的}}(x) \iff \neg \mathbf{S}(B(x)))$ のただ一つだけを定義とする。）

D2a :  ∀x  ( Ext原理的(x) ⇔ ¬𝐒(B(x)) )
D2b :  ∀x  ( Gen(x) ⇔ ∃a ( P(a, x) ∧ ¬P(x, a) ) )
D2c :  ∀x  ( Begin(x) ⇔ ∃c  Before(c, Loc(x)) )
D2d :  ∀x  ( End(x) ⇔ ∃c  Before(Loc(x), c) )
D2e :  ∀x  ( AbsoluteNothing(x) ⇔ ¬B(x) )
【読み方】D2a：$x$ が観念の「原理的外部」にあるとは、$x$ の存在が観念 $\mathbf{S}(B(x))$ として成立していないことである。D2b：一方的生成 $Gen(x)$ とは、双方向性なしに、ある $a$ から $x$ へ非対称に思い描かれ生み出されること（時系列的な従属関係、本文 p.45）である。D2c：$x$ に始まりがあるとは、$x$ の座標より前の座標があることである。D2d：$x$ に終わりがあるとは、$x$ の座標より後の座標があることである。D2e：$x$ が絶対的無であるとは、$x$ が実在しないこと（$\neg B(x)$）である。
[LaTeX] $$\text{D2a}: \quad \forall x \, \left(Ext_{\text{原理的}}(x) \iff \neg \mathbf{S}(B(x))\right)$$ $$\text{D2b}: \quad \forall x \, \left(Gen(x) \iff \exists a \, (P(a, x) \land \neg P(x, a))\right)$$ $$\text{D2c}: \quad \forall x \, \left(Begin(x) \iff \exists c \, \text{Before}(c, Loc(x))\right)$$ $$\text{D2d}: \quad \forall x \, \left(End(x) \iff \exists c \, \text{Before}(Loc(x), c)\right)$$ $$\text{D2e}: \quad \forall x \, \left(\text{AbsoluteNothing}(x) \iff \neg B(x)\right)$$
D3（原理的存在の定義） 本文 第3章 p.40・終章 p.53・付録『重要な点』

観念 $S(x)$ として成立し、かつ他と相互成立の対称性を持つものを「原理的存在（$PE$）」と定義する。（※ Rev. 4 の D3b「$Concept(x) \implies B(x)$」は、定義ではなく、他の式から導ける（T6 の系）ため外した。）

D3 :  ∀x  ( PE(x) ⇔ ( S(x) ∧ ∀y ( P(x, y) ⇔ P(y, x) ) ) )
【読み方】原理的存在とは、観念として成立し、かつ、どの存在 $y$ との間にも一方向だけの成立関係がない（成立関係があれば、必ず双方向である）ことである。
[LaTeX] $$\text{D3}: \quad \forall x \, \left(PE(x) \iff (S(x) \land \forall y \, (P(x, y) \iff P(y, x)))\right)$$
D4（共在・予在・原理的同一の非時間的定義） 本文 第5章 p.45–47・第6章 p.49–51・付録

時系列 $F_{\text{time}}$ を前提としない原理的領域において、「同時（$\text{CoPresent}$）」「予め存在する（$\text{AlreadyPresent}$）」「原理的に同一（$\text{Same}$）」を以下の連言によって定義する。

D4a :  ∀x ∀y  ( CoPresent(x, y) ⇔ ( Loc(x) = c₀ ∧ Loc(y) = c₀ ) )
D4b :  ∀x  ( AlreadyPresent(x) ⇔ ( Loc(x) = c₀ ∧ PE(x) ∧ ¬Gen(x) ) )
D4c :  ∀x ∀y  ( Same(x, y) ⇔ ( PE(x) ∧ PE(y) ∧ Loc(x) = Loc(y) ) )
【読み方】D4a：$x$ と $y$ が共在（同時）であるとは、ともに単一座標 $c_0$ 上に位置することである。D4b：予め存在する（予在）とは、単一座標 $c_0$ 上で、原理的存在として、一方的生成なしに存在していることである。D4c：$x$ と $y$ が原理的に同一の存在であるとは、ともに原理的存在であり、同じ座標に位置することである（本文 p.46「原理的には同一の存在である」）。これは数としての同一（$x = y$）ではない。$x$ と $y$ は、別々の実在でありながら、原理的に同一でありうる。
[LaTeX] $$\text{D4a}: \quad \forall x \forall y \, \left(\text{CoPresent}(x, y) \iff (Loc(x) = c_0 \land Loc(y) = c_0)\right)$$ $$\text{D4b}: \quad \forall x \, \left(\text{AlreadyPresent}(x) \iff (Loc(x) = c_0 \land PE(x) \land \neg Gen(x))\right)$$ $$\text{D4c}: \quad \forall x \forall y \, \left(\text{Same}(x, y) \iff (PE(x) \land PE(y) \land Loc(x) = Loc(y))\right)$$
D5（真理と意味の定義） 前文・終章 p.53–54

真理とは追究の作用において観念が現前する事象そのものであり（D5a：任意の論理式についての定義図式）、意味 $M(x)$ とは外部の目的から付与されるものではなく、存在 $B(x)$ そのものである（D5b）。

D5a（図式） :  Truth(φ) ⇔ 𝐒(φ)
D5b :  ∀x  ( M(x) ⇔ B(x) )
【読み方】D5a：真理とは観念として現前する事象そのものである。D5b：意味があること（$M$）と存在すること（$B$）は同値である。（※ D5a は T1〜T8 の導出には使われない。本書の真理観を形式の上に位置づけるための定義である。）
[LaTeX] $$\text{D5a（図式）}: \quad Truth(\phi) \iff \mathbf{S}(\phi)$$ $$\text{D5b}: \quad \forall x \, (M(x) \iff B(x))$$

Ⅲ. 公理（Axioms: A1, A2, A4〜A8 ＆ メタ理論上の制限 A3）

本体系の対象言語 $\mathcal{L}$ における公理は、A1, A2（公理図式）と A4, A5, A6, A7, A8 の7つである（A8 も公理図式）。A3 は対象言語の公理（論理式）ではなく、メタ理論上の制限として明記する。これらの公理は演繹されたものではなく、本書が置く前提である（第Ⅶ節 Q3）。

A1（観念包摂の公理図式） 本文 第1章 p.32–33・第3章 p.39–40

いかなる論理式 $\phi$ であれ、成り立つことは、必ず観念 $\mathbf{S}$ を介して、その内部で成り立つ。

A1（図式） :  φ ⇒ 𝐒(φ)
【読み方】任意の論理式 $\phi$ について、$\phi$ が成り立つならば、それは観念 $\mathbf{S}(\phi)$ として成り立っている。（※前件は「$\phi$ が主張される」ではなく「$\phi$ が成り立つ」である。A1 は、A7・A8 とともに、本書第3章が「仮説」として置く内容（あらゆる存在は観念そのものである）を形式化した強い前提であり、本体系の結論の重みはここにある。）
[LaTeX] $$\text{A1（図式）}: \quad \phi \implies \mathbf{S}(\phi)$$
A2（枠組み内部性の公理図式） 本文 第1章 p.32–34

「客観的事実」や「物質」を含むいかなる便宜的枠組み $F(\phi)$ も、観念の外部にあるのではなく、観念の作用 $\mathbf{S}(\phi)$ として成立する。

A2（図式） :  F(φ) ⇒ 𝐒(φ)
【読み方】任意の論理式 $\phi$ について、それが便宜的枠組み $F(\phi)$ であるならば、観念 $\mathbf{S}(\phi)$ の内部の働きとして成立する。（※ A2 は T1〜T8 の導出には使われない。「便宜」を形式の上に位置づけるための公理である。）
[LaTeX] $$\text{A2（図式）}: \quad F(\phi) \implies \mathbf{S}(\phi)$$
A3（【メタ理論上の制限】自律体系・多重説明に関するメタ規則） 本文 第1章 p.34・付録

【位置づけの明記】本項目 A3 は、対象言語 $\mathcal{L}$ の内部で記述される公理（論理式）ではなく、本形式体系を外部から参照・検証する際のメタ理論上の制限である。したがって対象言語 $\mathcal{L}$ に未定義の述語やソートを追加するものではない。

(1) 本形式体系の内部記号（$B, S, PE, Loc$ 等）の意味は、本データの定義・公理と【読み方】によって定まる。外部の異なる哲学体系・科学体系における同じ語の定義を当てはめた推論は、本体系の検証ではなく、別の体系についての推論になる。
(2) それぞれ異なる公理系の上に無矛盾に閉じた説明モデルは、メタ理論において複数独立に併存しうる（「説明になってさえいれば、答えは何通りあってもいい」）。
A4（相互成立の対称性公理） 本文 第4章 p.42・第5章 p.45–47

「ある対象を思い描く行為」と「ある対象によって思い描かれる行為」は原理的に同等であり、作用する側とされる側の間に一方向の従属関係はない。

A4 :  ∀x ∀y  ( P(x, y) ⇔ P(y, x) )
【読み方】すべての存在 $x, y$ について、$x$ が $y$ を思い描くことと $y$ が $x$ を思い描くことは同等である。
[LaTeX] $$\text{A4}: \quad \forall x \forall y \, (P(x, y) \iff P(y, x))$$
A5（単一座標と連続性の公理） 本文 第5章 p.45–47

原理的には時系列（別座標の並び）は存在しない。座標はただ一つ $c_0$ であり、前後の関係は異なる座標の間にしか成り立たず、$c_0$ では「今が今をもたらし続ける」連続性 $C(c_0, c_0)$ がある。

A5 :  ∀c ( c = c₀ )  ∧  ∀c ∀c' ( Before(c, c') ⇒ c ≠ c' )  ∧  C(c₀, c₀)   （c, c' は座標ソートの変数）
【読み方】すべての座標 $c$ は唯一の $c_0$ に一致する。前後の関係は異なる座標の間にしか成り立たない。単一座標 $c_0$ では非時間的連続性 $C(c_0, c_0)$ が展開されている。
（※ Rev. 4 では $c$ が存在（個体）の変数だったため、第1連言肢が「すべての存在は一つの個体 $c_0$ と同一である」という意味になり、個人・世界・他者の区別が書けなかった。$c$ を座標ソートの変数にして、「座標が一つ」という本来の意味にした。Rev. 4 の第2連言肢「$PE(x) \implies Loc(x) = c_0$」は、第1連言肢から導ける（補題 L1）ので外した。）
[LaTeX] $$\text{A5}: \quad \forall c \, (c = c_0) \land \forall c \, \forall c' \, (\text{Before}(c, c') \implies c \neq c') \land C(c_0, c_0) \quad (c, c' \text{ は座標ソートの変数})$$
A6（全体作用による個体制約公理） 本文 第5章【補足】p.48

$S_{\text{ind}}$ は個人の個別観念を表す存在の定数であり、$y$ は任意の存在を走る変数である。単一座標 $c_0$ 上では個別観念 $S_{\text{ind}}$ とすべての存在 $y$ が同時に共在して作用するため、一個人の観念 $S_{\text{ind}}$ のみによって世界全体を恣意的に変更することはできない。

A6 :  ( ∀y  CoPresent(Sind, y) ) ⇒ Limited(Sind)
【読み方】個人の観念 $S_{\text{ind}}$ がすべての存在 $y$ と同一座標 $c_0$ 上に共在しているならば、個人の裁量は制約される（$\text{Limited}(S_{\text{ind}})$）。
[LaTeX] $$\text{A6}: \quad \left(\forall y \, \text{CoPresent}(S_{\text{ind}}, y)\right) \implies \text{Limited}(S_{\text{ind}})$$
A7（観念の実在性の公理） 本文 第3章 p.40・終章 p.52（Rev. 4 の D1b）

観念として成立しているものは、すべて実在する。

A7 :  ∀x  ( S(x) ⇒ B(x) )
【読み方】$x$ が観念であるならば、$x$ は実在する。
[LaTeX] $$\text{A7}: \quad \forall x \, (S(x) \implies B(x))$$
A8（対象措定の公理図式） 本文 第2章 p.37–38・第3章 p.40（Rev. 4 の D1c）

存在 $x$ についての命題 $\phi(x)$ が、どのようなものであれ、観念 $\mathbf{S}(\phi(x))$ として措定・現前するならば、その存在 $x$ は観念 $S(x)$ として成立している。

A8（図式） :  ∀x  ( 𝐒(φ(x)) ⇒ S(x) )   （φ(x) は x を自由変数として含む任意の論理式）
【読み方】存在 $x$ について、いかなる命題 $\phi(x)$ であれ観念の内部で措定されたならば、$x$ は観念 $S(x)$ として成立する。
（※ Rev. 4 の D1c は「$\mathcal{L}$ の任意の単項述語記号 $\Phi$」についての図式で、定義された記号（$\text{AbsoluteNothing}$ など）にも当てはめていたため、定義が新しい主張を生む形になっていた。Rev. 5 では任意の論理式についての図式とし、前提の強さを公理の側に明示した。）
（※ A8 は A1 と合わせると強い帰結を持つ。どの存在 $x$ についても何かが成り立つので（例えば $x = x$）、A1 によりそれは観念 $\mathbf{S}$ としても成り立ち、A8 により $x$ は観念である。したがって、領域のすべての存在は観念であり（$\forall x \, S(x)$）、A7 により実在する（$\forall x \, B(x)$）。本書第3章の「あらゆる存在は観念そのものである」は、この前提の形で体系に入っている。）
[LaTeX] $$\text{A8（図式）}: \quad \forall x \, (\mathbf{S}(\phi(x)) \implies S(x)) \quad (\phi(x) \text{ は } x \text{ を自由変数として含む任意の論理式})$$

Ⅳ. 定理の導出（Derivations: 補題 L1、定理 T1〜T8）

定義 D1〜D5 と公理 A1, A2, A4〜A8 のみから、自然言語の補足に依存せず、一階述語論理の標準的な推論規則（モーダスポネンス MP、連言・含意・双条件の導入と除去、背理法、対偶、二重否定の除去、推移律、全称例化・全称化、存在例化、量化子の否定交換、等号の反射・対称・推移と代入、定義の展開）のみで、各定理を省略なく導出する。（※導出は手で書いたもので、各段は上の推論規則で確かめられる。この導出は、証明支援系 Lean 4 によっても機械的に確かめた（第0節「■ Lean 4 による機械検証」）。）

【補題】
L1（すべての存在は同一座標点上にある — 本文 第5章 p.47） 成立根拠：公理 A5（第1連言肢）
⊢  ∀x  ( Loc(x) = c₀ )
[LaTeX] $$\vdash \forall x \, (Loc(x) = c_0)$$
【導出】
  1. 任意の存在 $x$ をとる。$Loc(x)$ は座標ソートの項である。
  2. 公理 A5 の第1連言肢 $\forall c \, (c = c_0)$ を $c := Loc(x)$ に全称例化すると、$Loc(x) = c_0$。
  3. 全称化により、$\vdash \forall x \, (Loc(x) = c_0)$ が導出された。 $\blacksquare$
【第1段階：認識と存在の統合（第1章〜第3章）】
T1（外部実在仮説の自己崩落） 成立根拠：公理図式 A1 と定義 D2a の組み合わせ（背理法）
⊢  ¬∃x  ( B(x) ∧ Ext原理的(x) )
[LaTeX] $$\vdash \neg \exists x \, (B(x) \land Ext_{\text{原理的}}(x))$$
【導出】
  1. $\exists x \, (B(x) \land Ext_{\text{原理的}}(x))$ と仮定する（背理法の仮定）。
  2. 存在例化により、ある存在 $a$ について $B(a) \land Ext_{\text{原理的}}(a)$ を得る。
  3. ステップ2に連言除去を適用し、$B(a)$ と $Ext_{\text{原理的}}(a)$ をそれぞれ得る。
  4. 公理図式 A1（$\phi \implies \mathbf{S}(\phi)$）において $\phi := B(a)$ と置くと、$B(a) \implies \mathbf{S}(B(a))$。これとステップ3の $B(a)$ より、MP で $\mathbf{S}(B(a))$ を得る。
  5. 定義 D2a を $a$ に全称例化し双条件除去を適用すると、$Ext_{\text{原理的}}(a) \implies \neg \mathbf{S}(B(a))$。これとステップ3の $Ext_{\text{原理的}}(a)$ より、MP で $\neg \mathbf{S}(B(a))$ を得る。
  6. ステップ4とステップ5を連言導入で結合すると、明示的矛盾 $\mathbf{S}(B(a)) \land \neg \mathbf{S}(B(a))$（$\bot$）が導出される。
  7. よって背理法（否定導入）により仮定1は棄却され、$\vdash \neg \exists x \, (B(x) \land Ext_{\text{原理的}}(x))$ が導出された。 $\blacksquare$
T2（観念存在定理 — 第3章の中心命題） 成立根拠：公理図式 A1、定義 D1、公理 A7
⊢  ∀x  ( B(x) ⇔ S(x) )
[LaTeX] $$\vdash \forall x \, (B(x) \iff S(x))$$
【導出】

(1) D1 $\forall x \, (S(x) \iff \mathbf{S}(B(x)))$ 左辺 $S(x)$ は真。右辺 $V_{\mathcal{M}}(\mathbf{S}(B(x))) = V_{\mathcal{M}}(B(x))$ は真。真。

(3) D2b $\forall x \, (Gen(x) \iff \exists a \, (P(a, x) \land \neg P(x, a)))$ 左辺は偽。$P$ はすべての組で真なので、$P(a, x) \land \neg P(x, a)$ を満たす $a$ はなく、右辺も偽。真。
(4) D2c $\forall x \, (Begin(x) \iff \exists c \, \text{Before}(c, Loc(x)))$ 左辺は偽。$\text{Before}$ は空なので右辺も偽。真。
(5) D2d $\forall x \, (End(x) \iff \exists c \, \text{Before}(Loc(x), c))$ 同様に、左辺も右辺も偽。真。
(6) D2e $\forall x \, (\text{AbsoluteNothing}(x) \iff \neg B(x))$ 左辺は偽。右辺 $\neg$ 真 $=$ 偽。真。
(7) D3 $\forall x \, (PE(x) \iff (S(x) \land \forall y \, (P(x, y) \iff P(y, x))))$ 左辺は真。$S(x)$ は真で、$P$ は対称なので右辺も真。真。
(8) D4a $\forall x \forall y \, (\text{CoPresent}(x, y) \iff (Loc(x) = c_0 \land Loc(y) = c_0))$ 左辺は真。$Loc(x) = k = I(c_0)$、$Loc(y) = k$ なので右辺も真。真。
(9) D4b $\forall x \, (\text{AlreadyPresent}(x) \iff (Loc(x) = c_0 \land PE(x) \land \neg Gen(x)))$ 左辺は真。右辺 真 $\land$ 真 $\land \neg$ 偽 $=$ 真。真。
(10) D4c $\forall x \forall y \, (\text{Same}(x, y) \iff (PE(x) \land PE(y) \land Loc(x) = Loc(y)))$ 左辺は真。右辺 真 $\land$ 真 $\land$ 真（$k = k$）。真。
(11) D5a（図式） $Truth(\phi) \iff \mathbf{S}(\phi)$ 任意の $\phi$ に対し $V_{\mathcal{M}}(Truth(\phi)) = V_{\mathcal{M}}(\phi) = V_{\mathcal{M}}(\mathbf{S}(\phi))$。常に真。
(12) D5b $\forall x \, (M(x) \iff B(x))$ 左辺も右辺も真。真。
(13) A1（図式） $\phi \implies \mathbf{S}(\phi)$ 任意の $\phi$ に対し $(V_{\mathcal{M}}(\phi) \implies V_{\mathcal{M}}(\phi))$。常に真。
(14) A2（図式） $F(\phi) \implies \mathbf{S}(\phi)$ 任意の $\phi$ に対し $(V_{\mathcal{M}}(\phi) \implies V_{\mathcal{M}}(\phi))$。常に真。
(15) A4 $\forall x \forall y \, (P(x, y) \iff P(y, x))$ $P$ はすべての組で真なので対称。真。
(16) A5 $\forall c \, (c = c_0) \land \forall c \, \forall c' \, (\text{Before}(c, c') \implies c \neq c') \land C(c_0, c_0)$ $D_C = \{k\}$ なので第1連言肢は真。$\text{Before}$ は空なので第2連言肢は真。$C(k, k)$ は真。真。
(17) A6 $(\forall y \, \text{CoPresent}(S_{\text{ind}}, y)) \implies \text{Limited}(S_{\text{ind}})$ 前件 $\forall y \, \text{CoPresent}(s, y)$ は真、後件 $\text{Limited}(s)$ は真。真。
(18) A7 $\forall x \, (S(x) \implies B(x))$ 前件も後件も真。真。
(19) A8（図式） $\forall x \, (\mathbf{S}(\phi(x)) \implies S(x))$ 後件 $S(x)$ がどの $x$ でも真なので、任意の論理式 $\phi(x)$ について真。

【3. 結論】

  1. 無矛盾性：構造 $\mathcal{M}$ において、定義と公理の全19式はすべて真になる（$\mathcal{M} \models \text{D1–D5} \cup \{\text{A1, A2, A4–A8}\}$）。したがって健全性定理により、本体系から矛盾（$\psi \land \neg \psi$）は導かれない（$\text{D1–D5}, \text{A1, A2, A4–A8} \nvdash \bot$）。
  2. 導出可能性：第Ⅳ節において、補題 L1、定理 T1〜T8 と各系は、上記の定義と公理のみから推論規則によって導出された（$\text{D1–D5}, \text{A1, A2, A4–A8} \vdash \text{T1–T8}$）。
  3. このモデルが示すこと：個人 $s$・他者 $t$・世界 $w$ は、数としては互いに別の存在でありながら、同一座標点 $k$ 上に同時に存在し、どれも同格の原理的存在であり、原理的には同一（$\text{Same}$）である。存在どうしの関係（$P$, $\text{CoPresent}$, $\text{Same}$）はすべて対称で、上下や主従はない。

以上により、本体系は無矛盾であり、T1〜T8 はその定義と公理から導かれる。ただし、これは前提（公理）が正しいことを示すものではない（第0節「証明の二層構造」）。 $\blacksquare$

Ⅶ. 想定される外部批判・疑問への論理的回答（FAQ）

Q1. 「成り立つことはすべて『そう思う』として成り立つ（A1）」から「対象そのものが観念である（T2）」を導くのは、認識論と存在論の混同（循環論法）ではないか？

【回答】
形式の上で循環はない。T2 は A1・D1・A7 から導かれ、結論 T2 を前提として使う段はない。認識と存在を結ぶ主張は、前提である A1・A7・A8 の側に明示してあり、これは本書第3章が「仮説」として置く内容にあたる（本書は、この仮説が第4章〜第6章の時間と無の問いと矛盾しないことを検証し、終章で結論とする）。T1 が示すのは、この前提のもとでは「観念（認識）の外側に独立した別の存在領域がある」という仮定が成り立たないことである。なお、「認識作用」と「対象そのもの（物自体）」を分けなければならないという主張も、それ自体が別の前提（カント的・近代的な主客二元論）に立っている。また本書における観念は「脳内の主観的イメージ（幻）」ではなく、対象（物質・肉体）も認識も同格に含む実在の原理（T3）であるため、物質の実在性が損なわれることはない。

Q2. 「主客や自他の区分は便宜（D2）であり単一座標で一つである」としながら、前文や終章で「人間それぞれの境界を守るべきだ」と主張するのは内部矛盾ではないか？

【回答】
矛盾しない。「単一座標で一つ」とは、座標が一つしかないこと（A5）と、すべての存在が原理的に同一であること（D4c、T8 の系2）であり、すべてが数として一つの個体だという意味ではない。個人・他者・世界は、それぞれ別の実在として、同一座標点 $c_0$ 上に同時に存在しうる（第Ⅵ節のモデル $\mathcal{M}$ がその例。Rev. 4 とは違い、本体系は、個人と世界が一つの個体であることを要求しない）。「便宜 $F$」とは「無価値な幻」という意味ではなく、単一座標 $c_0$ 上の全体が、人間や個別の世界として具体的に成立するための構造上の区分である。そして T3 と T8 により、各人が生きる個別の世界（便宜によって形作られた喜びや愛着の領域）もまた、物理学の法則や宇宙全体と同格の「原理的存在（実在）」として肯定される。存在に上下の優劣がない（上位の客観的真理から下位の主観を否定できない）からこそ、外部の尺度で他者の境界を踏み荒らし否定する行為は論理的に不当となる。

Q3. 公理 A4（相互成立の対称性）や定義 D5b（存在＝意味）は、演繹されたものではなく著者が置いた独立の前提（再定義）ではないか？

【回答】
その通りである。A4・D5b に加え、存在と観念を結ぶ A1・A7・A8、単一座標の A5 も、本書が置く前提である。いかなる数学や論理学の体系も、無から定理を生むことはできず、体系の性格を決定づける「公理」と「定義」を出発点として置く。従来の哲学が「主客の非対称性（二元論）」や「存在と意味の分離」を暗黙の前提として採用してきたのに対し、本書は「相互成立（A4）」や「存在＝意味（D5b）」などを明示的な前提として選び、そこから矛盾なく閉じる体系を示している。本データが示すのは、この前提から結論が矛盾なく導かれることであり、前提そのものの正しさではない。

Q4. 「すべての概念が予め存在する（T7）」なら、人間が新しく何かを思いつくという経験（新規性）が説明できないのではないか？

【回答】
「新しく生まれたかのように見える」のは、人間が便宜的時系列（$F_{\text{time}}$：過去から未来への流れ）の枠組みを通して現象を捉えているためである。原理的座標 $c_0$ においては、一方的な生成（$Gen$）はない（T4）。最初から全体構造の中に含まれている概念 $x$ と人間 $a$ の間に成立関係があるとすれば、それは必ず相互の成立（$P(a, x) \iff P(x, a)$、A4）であり、連続性 $C(c_0, c_0)$ の中で現前している。これは数学において「新しい定理が発明されるのではなく、最初から論理空間に存在していた定理が発見される」と考える立場と同じ構造である。

Q5. 定理 T6 は「思考対象としての無」が有になることを示しただけで、「思考も認識もされない絶対的無」の不可能性までは否定できていないのではないか？

【回答】
本体系では、絶対的無とは実在しないこと（D2e）なので、「実在する絶対的無」は定義の上で成り立たない。そして「思考も認識もされない絶対的無」、つまり $\text{AbsoluteNothing}(a)$ が成り立ちながら $\mathbf{S}(\text{AbsoluteNothing}(a))$ が成り立たないものは、A1（成り立つことは、すべて「そう思う」としても成り立つ）によって退けられる。さらに T6 により、絶対的無にあたる存在そのものがない。ただし、本体系が用いる古典一階論理は、何かが存在すること（領域が空でないこと）を最初から前提にしているため、「何も存在しない」という状態そのものは、この体系ではもともと表せない。T6 が示すのは「領域のどの存在も絶対的無ではない」ことまでであり、本文 p.49 の「『無』はおろか、『始まり』さえ認める必要性はない」に対応する。また、この結論の強さは、A1・A8 という前提によるものである。

Q6. 個人・世界・座標を別々のものとして扱うと、存在の間に上下（階層）が生じないか？

【回答】
生じない。別々であることは、数として区別されるということであり、上下の順序を含まない。上下や主従が生じるのは、片方向にだけ成り立つ関係（従属・一方的生成）がある場合だが、本体系では、思い描く関係は対称であり（A4）、一方的生成はなく（T4）、共在も対称であり（D4a）、すべての存在が同格の原理的存在・意味であり（T8 の系1）、原理的に同一である（T8 の系2）。座標は存在の一つではなく、存在の位置を表す別の型なので、座標と存在の間にも上下はない。原理的には同一の存在でありながら、それぞれの実在が同一座標点上に同時に存在できる（第Ⅵ節のモデル $\mathcal{M}$）、というのが本体系の描く世界である。
