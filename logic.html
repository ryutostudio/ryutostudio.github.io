0. 本データの目的と位置づけ（参照前の前提条件）

本ページに掲載する形式論理体系（記号・定義・公理・定理・無矛盾性証明）は、『世界の証明』の本文における主張に「論理的飛躍」「定義の混同」「暗黙の前提の密輸」が存在しないことを、構文論（機械的導出）および意味論（モデル理論）の双方から客観的に検算・可視化するための補助的な論理検証データ（仕様書）である。
本データの参照および批評にあたっては、以下の前提と方法論を厳密に共有するものとする。

■ 論考の前提・証明の定義・方法論について

あらゆる科学や哲学も、目指すところは完成された論理（説明）モデルの獲得であり、それはつまり「完全に閉じた論理」である。また「客観的事実」や「既存の科学の作法」というものも、本書と同じく一つの「便宜」に従い、主観に基づき扱われるものである。したがって、探求において本来行われるべき作業は、反証にも至らない不毛な懐疑ではなく、閉じた論理に到達することである。

本書における「証明」とは、この閉じた論理の中で、個人や世界の存在が疑問を残さず確かに成り立つことを明らかにし、確定させることである。そもそも数学や論理学を含むあらゆる「証明」とは、最小限の公理（前提）を敷いた閉じた体系の内部で命題が矛盾なく導かれることを示す作業に他ならない。本書は、非常に平易で身近な概念のみを最小限の公理として敷き、外部の仮定を持ち込まずに論を組み立てて世界と個人の実在を導き出している以上、広義の演繹的な証明であり、文字通り『世界の証明』として成立している。もし仮にいつか、科学が宇宙の謎を演繹的作法で解き明かしたとしても、「それは果たして根本的な説明になっているのか？」という問いは残るが、本書はその段階での論考を行なっているのである。

また、第1章・第2章（便宜としての枠組みと認識の根源としての観念）から第3章（あらゆる存在は観念そのものである）への展開に「認識論から存在論への飛躍がある」とみなすのも誤りである。なぜなら、「観念の外側に独立した客観的物質が存在するかもしれない」という想定や疑い自体が、第1章・第2章で示した通り「観念（そう思う）の働き」によって観念の内部で作り出された枠組みにすぎないからである。したがって、第1章・第2章の前提に立った時点で「認識」と「外的な存在」の間に原理的な上下・主従の隔たりはなく、さらに本書は第3章でそれを「仮説」として置いた上で、第4章〜第6章で時間や無の疑問がすべて矛盾なく解けることを検証し、終章で結論として回収することで飛躍なく論を閉じている。

その上で本書は、説明になってさえいれば答えは何通りあってもいいとしている。根本の前提に対する反証ができないのは、それを求める側も同じである。前提や論を受け入れるかは個人の自由であるが、一つの完結した説明として閉じているものに対し、部分的な切り取りによって懐疑を行うだけでは反証にはならない。時間や存在などに対して既存の定義付けだけを外部から当てはめようとすることも同様であり、論理的な批判としては成立しない。火を使わない料理はあるし、カレーライスにパスタを入れる必要はない。車に乗りながら自転車に乗ることはできないように、自らの前提の反証可能性を問わずに、別の体系の要素を当てはめるべきではないのである。

すなわち、本論考のような閉じた公理系（論理モデル）を検証する際の唯一の論理的作業とは、「提示された入り口（最小限の前提）に立ったとき、出口まで矛盾なく閉じているか」を確認することだけである。入り口に入ることを拒み、外部から無関係な要素や別の物差しを並べて批判を試みることは、論理的な批評ではなく、単に「対象のモデルを検証すること自体を放棄している（別の話をしている）」にすぎない。そもそも本論考は、他者と正しさを競い合ったり誰かを論破したりするためではなく、「正しさの押し付けや虚無から、人間それぞれが大切にしている世界（境界）と個人の存在を守る」という目的のために構築された論理構造である。したがって、この構造が「個人と世界の実在を矛盾なく証明し、守り切る仕組みとして完結しているか」という本筋を離れ、外部の異なる定義や前提を当てはめて否定しようとすることは、別体系の規則の持ち込みにあたり、本書の内部論理に対する批評としては噛み合わないのである。

■ 本論理式の適用範囲に関する3つの免責事項

1. 数式による世界の還元を目的としたものではない 本書の本質は、平易な日常言語によって個人と世界の実在およびその境界を守り切ることにあり、本ページの論理式が「数式そのものとして世界のすべてを説明している」と主張するものではない。あくまで本文の自然言語による推論に論理的飛躍がないことを検算するための補助ツールである。
2. 外部前提（主客二元論・直線的時間モデル）の排除 一般的な述語論理を素朴に適用すると、「認識の外部に客観的個体があらかじめ存在する」「時間は数直線上の前後関係である」という外部の前提が無自覚に混入する。本モデルでは、本書の内部規則（枠組みの便宜化、観念の根源性、相互成立の対称性、単一座標の連続性）のみを原始規則として忠実に定式化している。
3. 検証の範囲（構文論的導出と意味論的無矛盾性の完全証明） 本モデルが示すのは、「第1章・第2章の初期定義（入口）および基本公理を採用したとき、自然言語の補足に頼ることなく形式的な推論規則（記号操作）のみで定理T1〜T8が100%機械的に導出可能であり（構文論的完全性）、かつ全公理を同時に充足する数学的モデル ℳ が存在する（意味論的無矛盾性）」という厳密な論理学的事実である。

Ⅱ. 定義群（Definitions：記号置換規則）

本文および付録において語の意味を規定する内部規則を、自然言語の解釈を挟まずに機械的代入が可能な双条件文（⇔）および含意（⇒）として定義する。

D1（観念と現前・実在の定義） 対応箇所：本文 第2章 p.37–38・第3章 p.40

理解・納得・認識・措定など、何かが「在る」として成立する働きはすべて「そう思う」という観念の成立 𝐒 である。また、便宜的分割を介さない原理的領域において、「x が存在する」という観念の成立 𝐒(B(x)) は、x 自身が観念 S(x) であることと同値であり（D1a）、観念として成立しているものはすべて実在 B(x) する（D1b）。さらに、いかなる述語 Φ であれ、対象 x に関する命題 Φ(x) が観念 𝐒(Φ(x)) として措定・現前するならば、その対象 x は観念 S(x) として成立している（D1c：対象措定による観念成立規則）。

D1a :  𝐒(B(x)) ⇔ S(x)
D1b :  S(x) ⇒ B(x)
D1c :  ∀Φ ∀x  ( 𝐒(Φ(x)) ⇒ S(x) )
【読み方】D1a：「x が存在する」と観念されることと x が観念であることは同値。D1b：観念であるならば実在する。D1c：x についていかなる規定 Φ(x) であれ観念の内部で措定された時点で、x は観念 S(x) として成立する（T7の機械的導出を完結させる橋渡し規則）。
[LaTeX] $$\text{D1a}: \quad \mathbf{S}(B(x)) \iff S(x)$$ $$\text{D1b}: \quad S(x) \implies B(x)$$ $$\text{D1c}: \quad \forall \Phi \forall x \, (\mathbf{S}(\Phi(x)) \implies S(x))$$
D2（便宜的枠組みと外部・生成・境界の定義） 対応箇所：本文 第1章 p.32–34・前文・詩「境界」

「主観と客観」「精神と物質」「過去・現在・未来（時系列 Ftime）」および「自他の境界」は、観念の内部で設定された構造上の分割規則（便宜 F）である。これに基づき、本体系において棄却対象となる「原理的外部（Ext原理的）」「無からの一方的生成（Gen）」「時間的境界（Begin, End）」「絶対的無（AbsoluteNothing）」を以下の論理式で厳密に定義する。

D2a（原理的外部） :  Ext原理的(x) ⇔ ¬𝐒(B(x) ∧ Ext原理的(x))  （および単項形：Ext原理的(x) ⇔ ¬𝐒(B(x))）
D2b（一方的生成） :  Gen(x) ⇔ ∃a ( P(a, x) ∧ ¬P(x, a) )
D2c（始点境界）   :  Begin(x) ⇔ ∃cbefore ( cbefore ≠ c₀ ∧ Loc(x) = c₀ )
D2d（終点境界）   :  End(x) ⇔ ∃cafter ( cafter ≠ c₀ ∧ Loc(x) = c₀ )
D2e（絶対的無）   :  AbsoluteNothing(x) ⇔ 𝐒(AbsoluteNothing(x)) ∧ ¬B(x)
【読み方】D2a：原理的外部とは観念の成立 𝐒 を介さずに外部存在すること。D2b：一方的生成とは双方向性なしに a から x へ一方向に生み出されること。D2c・D2d：始まりと終わりとは単一座標 c₀ の外側に前後の別座標が存在すること。D2e：絶対的無とは「絶対的無として措定されながら一切実在しない」こと。
[LaTeX] $$\text{D2a（原理的外部）}: \quad Ext_{\text{原理的}}(x) \iff \neg \mathbf{S}(B(x) \land Ext_{\text{原理的}}(x)) \quad (\text{単項形}: Ext_{\text{原理的}}(x) \iff \neg \mathbf{S}(B(x)))$$ $$\text{D2b（一方的生成）}: \quad Gen(x) \iff \exists a \, (P(a, x) \land \neg P(x, a))$$ $$\text{D2c（始点境界）}: \quad Begin(x) \iff \exists c_{\text{before}} \, (c_{\text{before}} \neq c_0 \land Loc(x) = c_0)$$ $$\text{D2d（終点境界）}: \quad End(x) \iff \exists c_{\text{after}} \, (c_{\text{after}} \neq c_0 \land Loc(x) = c_0)$$ $$\text{D2e（絶対的無）}: \quad \text{AbsoluteNothing}(x) \iff \mathbf{S}(\text{AbsoluteNothing}(x)) \land \neg B(x)$$
D3（原理的存在と概念の定義） 対応箇所：本文 第3章 p.40・終章 p.53・付録『重要な点』

観念 S(x) として成立し、かつ他と相互成立の対称性を持つものを「原理的存在（PE）」と定義する。また、思い描かれるあらゆる「概念（Concept）」は存在 B(x) の部分集合である。

D3a :  PE(x) ⇔ ( S(x) ∧ ∀y ( P(x, y) ⇔ P(y, x) ) )
D3b :  Concept(x) ⇒ B(x)
【読み方】D3a：原理的存在（PE）とは、観念として成立し、あらゆる存在と対等な双方向の成立関係にあること。D3b：概念であるならば存在する。
[LaTeX] $$\text{D3a}: \quad PE(x) \iff \left( S(x) \land \forall y \, (P(x, y) \iff P(y, x)) \right)$$ $$\text{D3b}: \quad Concept(x) \implies B(x)$$
D4（共在と予在の非時間的定義） 対応箇所：本文 第5章 p.45–47・第6章 p.49–51・付録

時系列 Ftime を前提としない原理的領域において、「同時（CoPresent）」と「予め存在する（AlreadyPresent）」を以下の連言によって定義する。

D4a :  CoPresent(x, y) ⇔ ( Loc(x) = c₀ ∧ Loc(y) = c₀ )
D4b :  AlreadyPresent(x) ⇔ ( Loc(x) = c₀ ∧ PE(x) ∧ ¬Gen(x) )
【読み方】D4a：共在（同時）とはともに単一座標 c₀ 上に位置すること。D4b：予め存在する（予在）とは、単一座標 c₀ 上で原理的存在として一方的生成（始まり）なしに存在していること。
[LaTeX] $$\text{D4a}: \quad \text{CoPresent}(x, y) \iff (Loc(x) = c_0 \land Loc(y) = c_0)$$ $$\text{D4b}: \quad \text{AlreadyPresent}(x) \iff (Loc(x) = c_0 \land PE(x) \land \neg Gen(x))$$
D5（真理と意味の定義） 対応箇所：前文・終章 p.53–54

真理とは追究の作用において観念が現前する事象そのものであり、意味 M(x) とは外部の目的から付与されるものではなく、存在 B(x) そのものである。

D5a :  Truth(φ) ⇔ 𝐒(φ)
D5b :  M(x) ⇔ B(x)
【読み方】D5a：真理とは観念として現前する事象そのものである。D5b：意味があること（M）と存在すること（B）は同値である。
[LaTeX] $$\text{D5a}: \quad Truth(\phi) \iff \mathbf{S}(\phi)$$ $$\text{D5b}: \quad M(x) \iff B(x)$$

Ⅲ. 公理群（Axioms）

本体系の出発点および構造的規則として採用される基本前提。

A1（観念包摂公理） 対応箇所：本文 第1章 p.32–33・第3章 p.39–40

いかなる対象や命題 φ であれ、それを措定・認識・説明する行為は必ず観念 𝐒 を介してその内部で成立する。

∀φ  ( φ ⇒ 𝐒(φ) )
【読み方】すべての命題・事象 φ について、φ が措定されるならば、それは観念 𝐒(φ) として成立している。
[LaTeX] $$\forall \phi \, (\phi \implies \mathbf{S}(\phi))$$
A2（枠組み内部性公理） 対応箇所：本文 第1章 p.32–34

「客観的事実」や「物質」を含むいかなる便宜的枠組み F も、観念の外部にあるのではなく、観念の作用として成立する。

∀φ  ( F(φ) ⇒ 𝐒(φ) )
【読み方】すべての便宜的枠組み F(φ) は、観念 𝐒(φ) の内部の働きとして成立する。
[LaTeX] $$\forall \phi \, (F(\phi) \implies \mathbf{S}(\phi))$$
A3（自律体系・多重説明公理） 対応箇所：本文 第1章 p.34・付録

本体系の内部概念に外部体系の定義 Dext を適用してはならない。また、内部で無矛盾に閉じた説明体系 L は複数存在しうる。

( Dext(x) ⇏ Dint(x) )  ∧  ∃L₁, L₂ … ( Consistent(Li) )
【読み方】外部体系の定義は本体系の内部定義を拘束せず、無矛盾に閉じた説明モデルは複数存在しうる。
[LaTeX] $$(D_{\text{ext}}(x) \not\Rightarrow D_{\text{int}}(x)) \land \exists L_1, L_2 \dots (\text{Consistent}(L_i))$$
A4（相互成立の対称性公理） 対応箇所：本文 第4章 p.42・第5章 p.45–47

「ある対象を思い描く行為」と「ある対象によって思い描かれる行為」は原理的に同等であり、作用する側とされる側の間に一方向の従属関係はない。

∀x ∀y  ( P(x, y) ⇔ P(y, x) )
【読み方】すべての x, y について、x が y を思い描くことと y が x を思い描くことは同等である。
[LaTeX] $$\forall x \forall y \, (P(x, y) \iff P(y, x))$$
A5（単一座標と連続性の公理） 対応箇所：本文 第5章 p.45–47

原理的には時系列（別座標の並び）は存在せず、すべての原理的座標は唯一の同一座標点 c₀ に一致し、すべての原理的存在は c₀ 上で展開され、「今が今をもたらし続ける」連続性 C(c₀, c₀) のみがある。

∀c ( c = c₀ )  ∧  ∀x ( PE(x) ⇒ Loc(x) = c₀ )  ∧  C(c₀, c₀)

Ⅶ. 想定される外部批判・疑問への論理的回答（FAQ）

Q1. 「対象を認識する行為が観念であること（A1）」から「対象そのものが観念であること（T2）」を導くのは、認識論と存在論の混同（循環論法）ではないか？

回答：
「認識作用」と「対象そのもの（物自体）」を分けなければならないという主張自体が、未証明の外部前提（カント的・近代的な主客二元論）に依存している。本体系のT1が示す通り、「観念（認識）の外側に独立した別の存在領域がある」という仮定自体が観念 𝐒 の内部から一歩も出られない以上、構造的に自己矛盾を起こして空集合となる。また本書における観念は「脳内の主観的イメージ（幻）」ではなく、対象（物質・肉体）も認識も同格に含む実在の原理（T3）であるため、物質の実在性が損なわれることはない。

Q2. 「主客や自他の区分は便宜（D2）であり単一座標で一つである」としながら、前文や終章で「人間それぞれの境界を守るべきだ」と主張するのは内部矛盾ではないか？

回答：
全く矛盾しない。「便宜 F」とは「無価値な幻」という意味ではなく、「単一座標 c₀ 上の全体が、人間や個別の世界として具体的に成立するための不可欠な構造規則」である。そしてT3により、各人が生きる個別の世界（便宜によって形作られた喜びや愛着の領域）もまた、物理学の法則や宇宙全体と1ミリも劣ることなく100%同格の「原理的存在（実在）」として肯定される。存在に上下の優劣がない（上位の客観的真理から下位の主観を否定できない）からこそ、外部の尺度で他者の境界を踏み荒らし否定する行為は論理的に不当となる。

Q3. 公理A4（相互成立の対称性）や定義D5（存在＝意味）は、演繹されたものではなく著者が置いた独立の前提（再定義）ではないか？

回答：
その通りである。いかなる数学や論理学の体系も、無から定理を生むことはできず、体系の性格を決定づける「基本公理」と「定義」を出発点として置く。従来の哲学が「主客の非対称性（二元論）」や「存在と意味の分離（虚無主義の温床）」を暗黙の公理として採用し、結果として「心身問題」や「生の無意味さ」という解決不能なバグを抱え込んだのに対し、本書は「相互成立（A4）」と「存在＝意味（D5）」を明示的な公理・定義として選択することで、それらの擬似問題をすべて解消し無矛盾に閉じるモデルを構築している。

Q4. 「すべての概念が予め存在する（T6）」なら、人間が新しく何かを思いつくという経験（新規性）が説明できないのではないか？

回答：
「新しく生まれたかのように見える」のは、人間が便宜的時系列（Ftime：過去から未来への流れ）の枠組みを通して現象を捉えているためである。原理的座標 c₀ においては、無から有が生じる（Gen）のではなく、最初から全体構造の中に含まれている概念 x と人間 a との相互成立（P(a, x) ⇔ P(x, a)）が連続性 C(c₀, c₀) の中で現前している。これは数学において「新しい定理が発明されるのではなく、最初から論理空間に存在していた定理が発見される」のと全く同じ構造である。

Q5. 定理T7は「思考対象としての無」が有になることを示しただけで、「思考も認識もされない絶対的無」の不可能性までは否定できていないのではないか？

回答：
「思考も認識もされないが、観念の外部に実在する絶対的無」という想定は、定理T1（観念の原理的外部 Ext原理的 の自己崩落）によってすでに棄却されている。言語や思考を用いて「思考の外にある無」を主張した瞬間にそれは観念の内部の措定（𝐒）となり、一切措定されないものは体系の内外を問わず議論の対象（命題）として成立しないため、どの道を通っても「絶対的無」が成立する余地は存在しない。
