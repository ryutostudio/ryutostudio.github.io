■ 論考の前提・証明の定義・方法論について

あらゆる科学や哲学も、目指すところは完成された論理（説明）モデルの獲得であり、それはつまり「完全に閉じた論理」である。また「客観的事実」や「既存の科学の作法」というものも、本書と同じく一つの「便宜」に従い、主観に基づき扱われるものである。したがって、探求において本来行われるべき作業は、反証にも至らない不毛な懐疑ではなく、閉じた論理に到達することである。

本書における「証明」とは、この閉じた論理の中で、個人や世界の存在が疑問を残さず確かに成り立つことを明らかにし、確定させることである。そもそも数学や論理学を含むあらゆる「証明」とは、最小限の公理（前提）を敷いた閉じた体系の内部で命題が矛盾なく導かれることを示す作業に他ならない。本書は、非常に平易で身近な概念のみを最小限の公理として敷き、外部の仮定を持ち込まずに論を組み立てて世界と個人の実在を導き出している以上、広義の演繹的な証明であり、文字通り『世界の証明』として成立している。もし仮にいつか、科学が宇宙の謎を演繹的作法で解き明かしたとしても、「それは果たして根本的な説明になっているのか？」という問いは残るが、本書はその段階での論考を行なっているのである。

また、第1章・第2章（便宜としての枠組みと認識の根源としての観念）から第3章（あらゆる存在は観念そのものである）への展開に「認識論から存在論への飛躍がある」とみなすのも誤りである。なぜなら、「観念の外側に独立した客観的物質が存在するかもしれない」という想定や疑い自体が、第1章・第2章で示した通り「観念（そう思う）の働き」によって観念の内部で作り出された枠組みにすぎないからである。したがって、第1章・第2章の前提に立った時点で「認識」と「外的な存在」の間に原理的な上下・主従の隔たりはなく、さらに本書は第3章でそれを「仮説」として置いた上で、第4章〜第6章で時間や無の疑問がすべて矛盾なく解けることを検証し、終章で結論として回収することで飛躍なく論を閉じている。

その上で本書は、説明になってさえいれば答えは何通りあってもいいとしている。根本の前提に対する反証ができないのは、それを求める側も同じである。前提や論を受け入れるかは個人の自由であるが、一つの完結した説明として閉じているものに対し、部分的な切り取りによって懐疑を行うだけでは反証にはならない。時間や存在などに対して既存の定義付けだけを外部から当てはめようとすることも同様であり、論理的な批判としては成立しない。火を使わない料理はあるし、カレーライスにパスタを入れる必要はない。車に乗りながら自転車に乗ることはできないように、自らの前提の反証可能性を問わずに、別の体系の要素を当てはめるべきではないのである。

すなわち、本論考のような閉じた公理系（論理モデル）を検証する際の唯一の論理的作業とは、「提示された入り口（最小限の前提）に立ったとき、出口まで矛盾なく閉じているか」を確認することだけである。入り口に入ることを拒み、外部から無関係な要素や別の物差しを並べて批判を試みることは、論理的な批評ではなく、単に「対象のモデルを検証すること自体を放棄している（別の話をしている）」にすぎない。そもそも本論考は、他者と正しさを競い合ったり誰かを論破したりするためではなく、「正しさの押し付けや虚無から、人間それぞれが大切にしている世界（境界）と個人の存在を守る」という目的のために構築された論理構造である。したがって、この構造が「個人と世界の実在を矛盾なく証明し、守り切る仕組みとして完結しているか」という本筋を離れ、外部の異なる定義や前提を当てはめて否定しようとすることは、別体系の規則の持ち込みにあたり、本書の内部論理に対する批評としては噛み合わないのである。

Ⅱ. 定義群（Definitions：記号置換規則）

本文および付録において語の意味を規定する内部規則を、自然言語の解釈を挟まずに機械的代入が可能な双条件文（⇔）および含意（⇒）として定義する。

D1（観念と現前・実在の定義） 対応箇所：本文 第2章 p.37–38・第3章 p.40

理解・納得・認識・措定など、何かが「在る」として成立する働きはすべて「そう思う」という観念の成立 𝐒 である。便宜的分割を介さない原理的領域において、「x が存在する」という観念の成立 𝐒(B(x)) は、x 自身が観念 S(x) であることと同値であり（D1a）、観念として成立しているものはすべて実在 B(x) する（D1b）。また、言語 ℒ の任意の単項述語 Φ に対し、個体 x に関する命題 Φ(x) が観念 𝐒(Φ(x)) として措定・現前するならば、その対象 x は観念 S(x) として成立している（D1c：対象措定の定義スキーマ）。

D1a :  ∀x  ( 𝐒(B(x)) ⇔ S(x) )
D1b :  ∀x  ( S(x) ⇒ B(x) )
D1c（スキーマ） :  ∀x  ( 𝐒(Φ(x)) ⇒ S(x) )   （※ Φ は ℒ の任意の単項述語記号）
【読み方】D1a：「x が存在する」と観念されることと x が観念であることは同値。D1b：観念であるならば実在する。D1c：x についていかなる述語 Φ(x) であれ観念の内部で措定されたならば、x は観念 S(x) として成立する。
[LaTeX] $$\text{D1a}: \quad \forall x \, (\mathbf{S}(B(x)) \iff S(x))$$ $$\text{D1b}: \quad \forall x \, (S(x) \implies B(x))$$ $$\text{D1c (Schema)}: \quad \forall x \, (\mathbf{S}(\Phi(x)) \implies S(x))$$
D2（便宜的枠組みと外部・生成・境界の定義） 対応箇所：本文 第1章 p.32–34・前文・詩「境界」

「主観と客観」「精神と物質」「過去・現在・未来（時系列 Ftime）」および「自他の境界」は、観念の内部で設定された構造上の分割規則（便宜 F）である。これに基づき、本体系において検証・棄却対象となる「原理的外部（Ext原理的：観念による存在措定 𝐒(B(x)) の外にあるとされる領域）」「無からの一方的生成（Gen：双方向性を持たない非対称な生成作用）」「時間的境界（Begin, End）」「絶対的無（AbsoluteNothing）」を以下の単一かつ一意な論理式で厳密に定義する。

D2a（原理的外部） :  ∀x  ( Ext原理的(x) ⇔ ¬𝐒(B(x)) )
D2b（一方的生成） :  ∀x  ( Gen(x) ⇔ ∃a ( P(a, x) ∧ ¬P(x, a) ) )
D2c（始点境界）   :  ∀x  ( Begin(x) ⇔ ∃cbefore ( cbefore ≠ c₀ ∧ Loc(x) = c₀ ) )
D2d（終点境界）   :  ∀x  ( End(x) ⇔ ∃cafter ( cafter ≠ c₀ ∧ Loc(x) = c₀ ) )
D2e（絶対的無）   :  ∀x  ( AbsoluteNothing(x) ⇔ ( 𝐒(AbsoluteNothing(x)) ∧ ¬B(x) ) )
【読み方】D2a：x が観念の「原理的外部」にあるとは、x の存在が観念 𝐒(B(x)) として成立していないことと定義する。D2b：一方的生成 Gen(x) とは、双方向性なしに a から x へ一方向（非対称）に思い描かれ生み出されること。D2c・D2d：始まりと終わりとは単一座標 c₀ の外側に別座標が存在すること。D2e：絶対的無とは「絶対的無として措定されながら一切実在しない」こと。
[LaTeX] $$\text{D2a（原理的外部）}: \quad \forall x \, \left(Ext_{\text{原理的}}(x) \iff \neg \mathbf{S}(B(x))\right)$$ $$\text{D2b（一方的生成）}: \quad \forall x \, \left(Gen(x) \iff \exists a \, (P(a, x) \land \neg P(x, a))\right)$$ $$\text{D2c（始点境界）}: \quad \forall x \, \left(Begin(x) \iff \exists c_{\text{before}} \, (c_{\text{before}} \neq c_0 \land Loc(x) = c_0)\right)$$ $$\text{D2d（終点境界）}: \quad \forall x \, \left(End(x) \iff \exists c_{\text{after}} \, (c_{\text{after}} \neq c_0 \land Loc(x) = c_0)\right)$$ $$\text{D2e（絶対的無）}: \quad \forall x \, \left(\text{AbsoluteNothing}(x) \iff (\mathbf{S}(\text{AbsoluteNothing}(x)) \land \neg B(x))\right)$$
D3（原理的存在と概念の定義） 対応箇所：本文 第3章 p.40・終章 p.53・付録『重要な点』

観念 S(x) として成立し、かつ他と相互成立の対称性を持つものを「原理的存在（PE）」と定義する。また、思い描かれるあらゆる「概念（Concept）」は存在 B(x) に含まれる。

D3a :  ∀x  ( PE(x) ⇔ ( S(x) ∧ ∀y ( P(x, y) ⇔ P(y, x) ) ) )
D3b :  ∀x  ( Concept(x) ⇒ B(x) )
【読み方】D3a：原理的存在（PE）とは、観念 S(x) として成立し、かつあらゆる存在 y と対等な双方向の成立関係にあることと定義する。D3b：概念であるならば存在する。
[LaTeX] $$\text{D3a}: \quad \forall x \, \left(PE(x) \iff (S(x) \land \forall y \, (P(x, y) \iff P(y, x)))\right)$$ $$\text{D3b}: \quad \forall x \, (Concept(x) \implies B(x))$$
D4（共在と予在の非時間的定義） 対応箇所：本文 第5章 p.45–47・第6章 p.49–51・付録

時系列 Ftime を前提としない原理的領域において、「同時（CoPresent）」と「予め存在する（AlreadyPresent）」を以下の連言によって定義する。

D4a :  ∀x ∀y  ( CoPresent(x, y) ⇔ ( Loc(x) = c₀ ∧ Loc(y) = c₀ ) )
D4b :  ∀x  ( AlreadyPresent(x) ⇔ ( Loc(x) = c₀ ∧ PE(x) ∧ ¬Gen(x) ) )
【読み方】D4a：共在（同時）とはともに単一座標 c₀ 上に位置すること。D4b：予め存在する（予在）とは、単一座標 c₀ 上で原理的存在として一方的生成（始まり）なしに存在していること。
[LaTeX] $$\text{D4a}: \quad \forall x \forall y \, \left(\text{CoPresent}(x, y) \iff (Loc(x) = c_0 \land Loc(y) = c_0)\right)$$ $$\text{D4b}: \quad \forall x \, \left(\text{AlreadyPresent}(x) \iff (Loc(x) = c_0 \land PE(x) \land \neg Gen(x))\right)$$
D5（真理と意味の定義） 対応箇所：前文・終章 p.53–54

真理とは追究の作用において観念が現前する事象そのものであり（D5a：文オペレータ定義スキーマ）、意味 M(x) とは外部の目的から付与されるものではなく、存在 B(x) そのものである（D5b）。

D5a（スキーマ） :  Truth(φ) ⇔ 𝐒(φ)   （※ φ は任意の整式 φ ∈ WFFℒ）
D5b :  ∀x  ( M(x) ⇔ B(x) )
【読み方】D5a：真理とは観念として現前する事象そのものである。D5b：意味があること（M）と存在すること（B）は同値である。
[LaTeX] $$\text{D5a (Schema)}: \quad Truth(\phi) \iff \mathbf{S}(\phi)$$ $$\text{D5b}: \quad \forall x \, (M(x) \iff B(x))$$

Ⅲ. 公理群および公理スキーマ（Axioms & Axiom Schemas）

A1（観念包摂および連言分配の公理スキーマ） 対応箇所：本文 第1章 p.32–33・第3章 p.39–40

いかなる整式（命題・事象）φ, ψ ∈ WFFℒ であれ、それを措定・認識・説明する行為は必ず観念 𝐒 を介してその内部で成立する（A1a）。また、連言命題 φ ∧ ψ が観念として成立・現前しているならば、その各構成要素 φ および ψ もそれぞれ観念として成立・現前している（A1b：連言に対する観念オペレータ 𝐒 の分配規則）。

A1a（包摂スキーマ） :  φ ⇒ 𝐒(φ)
A1b（分配スキーマ） :  𝐒(φ ∧ ψ) ⇒ ( 𝐒(φ) ∧ 𝐒(ψ) )
【読み方】A1a：任意の命題 φ が措定されるならば、それは観念 𝐒(φ) として成立する。A1b：「φ かつ ψ」が観念として成立しているならば、「φ が観念として成立」かつ「ψ が観念として成立」している（T1の背理法を命題論理と推論規則だけで完全に閉じるための明示的規則）。
[LaTeX] $$\text{A1a (Schema)}: \quad \phi \implies \mathbf{S}(\phi)$$ $$\text{A1b (Schema)}: \quad \mathbf{S}(\phi \land \psi) \implies (\mathbf{S}(\phi) \land \mathbf{S}(\psi))$$
A2（枠組み内部性の公理スキーマ） 対応箇所：本文 第1章 p.32–34

「客観的事実」や「物質」を含むいかなる便宜的枠組み F(φ)（φ ∈ WFFℒ）も、観念の外部にあるのではなく、観念の作用 𝐒(φ) として成立する。

A2（スキーマ） :  F(φ) ⇒ 𝐒(φ)
【読み方】任意の整式 φ について、それが便宜的枠組み F(φ) であるならば、観念 𝐒(φ) の内部の働きとして成立する。
[LaTeX] $$\text{A2 (Schema)}: \quad F(\phi) \implies \mathbf{S}(\phi)$$
A3（自律体系・多重説明のメタ公理） 対応箇所：本文 第1章 p.34・付録『論考の前提・証明の定義・方法論について』

本体系 𝒯world の内部概念に外部体系の定義集合 𝒟ext を適用してはならない。また、内部で無矛盾に閉じた説明体系（公理系）𝒯i は複数存在しうる。（※本公理は体系間の独立性を規定するメタ理論上の原則である。）

( 𝒟ext ∩ 𝒯world = ∅ )  ∧  ∃𝒯₁, 𝒯₂ … ( Consistent(𝒯i) )
【読み方】外部体系の定義集合は本体系の推論空間に属さず、無矛盾に閉じた説明モデルは複数成立しうる（説明になってさえいれば答えは何通りあってもよい）。
[LaTeX] $$(\mathcal{D}_{\text{ext}} \cap \mathcal{T}_{\text{world}} = \varnothing) \land \exists \mathcal{T}_1, \mathcal{T}_2 \dots (\text{Consistent}(\mathcal{T}_i))$$
A4（相互成立の対称性公理） 対応箇所：本文 第4章 p.42・第5章 p.45–47

「ある対象を思い描く行為」と「ある対象によって思い描かれる行為」は原理的に同等であり、作用する側とされる側の間に一方向の従属関係はない。

∀x ∀y  ( P(x, y) ⇔ P(y, x) )
【読み方】すべての個体 x, y について、x が y を思い描くことと y が x を思い描くことは同等である。
[LaTeX] $$\forall x \forall y \, (P(x, y) \iff P(y, x))$$
A5（単一座標と連続性の公理） 対応箇所：本文 第5章 p.45–47

原理的には時系列（別座標の並び）は存在せず、すべての原理的座標は唯一の同一座標点 c₀ に一致し、すべての原理的存在は c₀ 上で展開され、「今が今をもたらし続ける」連続性 C(c₀, c₀) のみがある。

∀c ( c = c₀ )  ∧  ∀x ( PE(x) ⇒ Loc(x) = c₀ )  ∧  C(c₀, c₀)
【読み方】すべての座標 c は唯一の c₀ に一致し、すべての原理的存在は c₀ 上に位置し、非時間的連続性 C(c₀, c₀) が展開されている。
[LaTeX] $$\forall c \, (c = c_0) \land \forall x \, (PE(x) \implies Loc(x) = c_0) \land C(c_0, c_0)$$
A6（全体作用による個体制約公理） 対応箇所：本文 第5章【補足】p.48

個人の思考（個別観念を表す個体定数 sind）も実在の一部であるが、単一座標 c₀ 上ではすべての存在 x が同時に共在して作用するため、一個人の観念 sind のみによって世界全体を恣意的に変更することはできない。

( ∀x  CoPresent(sind, x) ) ⇒ Limited(sind)
【読み方】個別観念 sind とあらゆる存在 x が同一座標 c₀ 上に共在しているならば、個人の裁量 sind は制約される（反独我論）。
[LaTeX] $$\left(\forall x \, \text{CoPresent}(s_{\text{ind}}, x)\right) \implies \text{Limited}(s_{\text{ind}})$$

Ⅳ. 定理群の構文論的導出証明（Syntactic Derivability of Theorems: T1〜T8）

公理（スキーマ）A1〜A6 と定義 D1〜D5 のみから、自然言語の補足に一切依存せず、一階述語論理の推論規則（モーダスポネンス MP、連言除去・導入、背理法、推移律、定義代入）のみで各定理を機械的に導出する。

【第1段階：認識と存在の統合（第1章〜第3章）】
T1（外部実在仮説の自己崩落） 成立根拠：公理スキーマ A1a, A1b と定義 D2a の組み合わせ（背理法）
⊢  ¬∃x  ( B(x) ∧ Ext原理的(x) )
【定理の意味】「観念の原理的な外側に独立して存在する x」なるものは存在しない（空集合である）。
[LaTeX] $$\vdash \neg \exists x \, (B(x) \land Ext_{\text{原理的}}(x))$$
【形式的証明（Mechanical Derivation）】
  1. $\exists x \, (B(x) \land Ext_{\text{原理的}}(x))$ と仮定する（背理法の仮定）。
  2. 存在例化（Existential Instantiation）により、ある個体定数 $a$ について $B(a) \land Ext_{\text{原理的}}(a)$ を得る。
  3. 公理スキーマ A1a（$\phi \implies \mathbf{S}(\phi)$）において $\phi := (B(a) \land Ext_{\text{原理的}}(a))$ と置くと、$(B(a) \land Ext_{\text{原理的}}(a)) \implies \mathbf{S}(B(a) \land Ext_{\text{原理的}}(a))$。
  4. ステップ2とステップ3より、モーダスポネンス（MP）で $\mathbf{S}(B(a) \land Ext_{\text{原理的}}(a))$ を得る。
  5. 公理スキーマ A1b（$\mathbf{S}(\phi \land \psi) \implies (\mathbf{S}(\phi) \land \mathbf{S}(\psi))$）において $\phi := B(a), \psi := Ext_{\text{原理的}}(a)$ と置き、ステップ4に MP を適用して $\mathbf{S}(B(a)) \land \mathbf{S}(Ext_{\text{原理的}}(a))$ を得る。
  6. ステップ5に連言除去（左項取り出し）を適用し、$\mathbf{S}(B(a))$ を得る。
  7. 一方、ステップ2に連言除去（右項取り出し）を適用すると $Ext_{\text{原理的}}(a)$ が得られ、これに定義 D2a（$Ext_{\text{原理的}}(a) \iff \neg \mathbf{S}(B(a))$）を適用すると、MP により $\neg \mathbf{S}(B(a))$ を得る。
  8. ステップ6の $\mathbf{S}(B(a))$ とステップ7の $\neg \mathbf{S}(B(a))$ を連言導入で結合すると、明示的矛盾 $\mathbf{S}(B(a)) \land \neg \mathbf{S}(B(a))$（$\bot$）が導出される。
  9. よって背理法（否定導入）により、仮定1は棄却され $\vdash \neg \exists x \, (B(x) \land Ext_{\text{原理的}}(x))$ が機械的に導出された。 $\blacksquare$
T2（観念存在定理 — 第3章の中心命題） 成立根拠：公理スキーマ A1a と定義 D1a, D1b の組み合わせ
⊢  ∀x  ( B(x) ⇔ S(x) )
【定理の意味】すべての個体 x について、x が存在する（実在する）ことと x が観念であることは論理的に同値である。
[LaTeX] $$\vdash \forall x \, (B(x) \iff S(x))$$
【形式的証明（Mechanical Derivation）】
  1. 任意の個体 $x$ をとる。公理スキーマ A1a において $\phi := B(x)$ と置くと、$B(x) \implies \mathbf{S}(B(x))$。
  2. 定義 D1a（$\mathbf{S}(B(x)) \iff S(x)$）より、双条件除去で $\mathbf{S}(B(x)) \implies S(x)$。
  3. ステップ1とステップ2に仮言三段論法（推移律）を適用すると、$B(x) \implies S(x)$ を得る。
  4. 逆方向は定義 D1b より、$S(x) \implies B(x)$ が直ちに与えられる。
  5. ステップ3とステップ4に双条件導入および全称化（Universal Generalization）を適用し、$\vdash \forall x \, (B(x) \iff S(x))$ が機械的に導出された。 $\blacksquare$
【第2段階：対象と像の同格化（第4章）】
T3（全存在の原理的同格性） 成立根拠：公理 A4 と定義 D3a の組み合わせにより定義上ただちに導出（＋T2との結合）
⊢  ∀x  ( B(x) ⇔ PE(x) )   （系：⊢ Limited(sind)）
【定理の意味】原理的存在の定義 D3a に対称性条件が組み込まれており、公理 A4 がその対称性を恒真として与えるため、A4 と D3a（および T2）から定義上ただちに「すべての存在 x は上下・主従のない原理的存在 PE(x) である」ことが導かれる。
[LaTeX] $$\vdash \forall x \, (B(x) \iff PE(x)) \quad \left(\text{系}: \vdash \text{Limited}(s_{\text{ind}})\right)$$
【形式的証明（Mechanical Derivation）】
  1. 任意の個体 $x$ をとる。公理 A4（$\forall x \forall y \, (P(x, y) \iff P(y, x))$）を全称例化すると、$\forall y \, (P(x, y) \iff P(y, x))$ が恒真命題として得られる。
  2. 命題論理の連言同値則（$\psi$ が恒真のとき $\phi \iff (\phi \land \psi)$）により、$S(x) \iff \left( S(x) \land \forall y \, (P(x, y) \iff P(y, x)) \right)$ が成り立つ。
  3. ステップ2の右辺は定義 D3a の右辺そのものであるから、D3a を用いて置換すると、定義上ただちに $S(x) \iff PE(x)$ を得る。
  4. 定理 T2（$B(x) \iff S(x)$）とステップ3に双条件の推移律を適用し全称化すると、$\vdash \forall x \, (B(x) \iff PE(x))$ が機械的に導出された。（※また、定数 $s_{\text{ind}}$ および任意の $x$ に対し、D1・A5・D4a より $\forall x \, \text{CoPresent}(s_{\text{ind}}, x)$ が成立するため、公理 A6 と MP により系 $\vdash \text{Limited}(s_{\text{ind}})$ がただちに導かれる。） $\blacksquare$
【第3段階：無の消去と無始無終の導出（第5章〜第6章）】
T4（無からの一方的生成の否定） 成立根拠：公理 A4（相互成立の対称性）と定義 D2b（非対称作用としてのGen定義）の組み合わせ
⊢  ∀x  ( ¬Gen(x) )
【定理の意味】定義 D2b において一方的生成 Gen(x) を非対称な作用として定義しているため、対称性を規定する公理 A4 と D2b の組み合わせにより、いかなる x についても ¬Gen(x) が導かれる。
[LaTeX] $$\vdash \forall x \, (\neg Gen(x))$$
【形式的証明（Mechanical Derivation）】
  1. 任意の個体 $x, a$ をとる。公理 A4 の全称例化より、$P(a, x) \iff P(x, a)$。
  2. 双条件除去により $P(a, x) \implies P(x, a)$ を得る。含意の定義（$\phi \implies \psi \equiv \neg \phi \lor \psi$）およびド・モルガンの法則により、$\neg (P(a, x) \land \neg P(x, a))$ を得る。
  3. ステップ2を $a$ について全称化すると $\forall a \, \neg (P(a, x) \land \neg P(x, a))$ となり、量化子の否定交換則により $\neg \exists a \, (P(a, x) \land \neg P(x, a))$ を得る。
  4. 定義 D2b（$Gen(x) \iff \exists a \, (P(a, x) \land \neg P(x, a))$）の対偶をステップ3に適用し $x$ について全称化すると、A4 と D2b の組み合わせにより $\vdash \forall x \, (\neg Gen(x))$ が機械的に導出された。 $\blacksquare$
T5（単一座標における無境界性＝無始無終） 成立根拠：公理 A5 と定義 D2c, D2d の組み合わせ
⊢  ∀x  ( PE(x) ⇒ ¬Begin(x) ∧ ¬End(x) )   （系：⊢ ¬Begin(World) ∧ ¬End(World)）
【定理の意味】公理 A5 により単一座標 c₀ の外側に別座標は存在しないため、定義 D2c・D2d より、すべての原理的存在（および世界定数 World）には始まりも終わりもない。
[LaTeX] $$\vdash \forall x \, (PE(x) \implies \neg Begin(x) \land \neg End(x)) \quad \left(\text{系}: \vdash \neg Begin(World) \land \neg End(World)\right)$$
【形式的証明（Mechanical Derivation）】
  1. 公理 A5 の第1連言肢 $\forall c \, (c = c_0)$ より、量化子の否定交換則を適用して $\neg \exists c \, (c \neq c_0)$ を得る。
  2. 一階述語論理の性質より、任意の論理式 $\psi$ に対して $\neg \exists c \, (c \neq c_0) \implies \neg \exists c \, (c \neq c_0 \land \psi)$ が成り立つため、MP により $\neg \exists c_{\text{before}} \, (c_{\text{before}} \neq c_0 \land Loc(x) = c_0)$ および $\neg \exists c_{\text{after}} \, (c_{\text{after}} \neq c_0 \land Loc(x) = c_0)$ を得る。
  3. ステップ2に定義 D2c および D2d の対偶を適用すると、任意の個体 $x$（個体定数 $World$ を含む）について $\neg Begin(x)$ および $\neg End(x)$、ならびに系 $\vdash \neg Begin(World) \land \neg End(World)$ が導出される。
  4. 連言導入で $\neg Begin(x) \land \neg End(x)$ とし、含意導入（弱化：$PE(x)$ の付加）および全称化を適用することで、$\vdash \forall x \, (PE(x) \implies \neg Begin(x) \land \neg End(x))$ が機械的に導出された。 $\blacksquare$
T6（全概念の予在定理 — 第6章） 成立根拠：定義 D3b, D4b・公理 A5・定理 T3, T4 の組み合わせ
⊢  ∀x  ( Concept(x) ⇒ AlreadyPresent(x) )
【定理の意味】すべての概念 x は、単一座標 c₀ 上に一方的生成（始まり）なしで予め存在している。
[LaTeX] $$\vdash \forall x \, (Concept(x) \implies \text{AlreadyPresent}(x))$$
【形式的証明（Mechanical Derivation）】
  1. 任意の個体 $x$ について $Concept(x)$ を仮定する。
  2. 定義 D3b（$Concept(x) \implies B(x)$）とステップ1より、MP で $B(x)$ を得る。
  3. 定理 T3（$B(x) \iff PE(x)$）とステップ2より、MP で $PE(x)$ を得る。
  4. 公理 A5 の第2連言肢（$PE(x) \implies Loc(x) = c_0$）とステップ3より、MP で $Loc(x) = c_0$ を得る。
  5. 定理 T4（$\forall x \, \neg Gen(x)$）の全称例化より、$\neg Gen(x)$ を得る。
  6. ステップ4、ステップ3、ステップ5を連言導入で結合し、$Loc(x) = c_0 \land PE(x) \land \neg Gen(x)$ を得る。
  7. 定義 D4b をステップ6に適用して $\text{AlreadyPresent}(x)$ を得る。含意導入および全称化により、$\vdash \forall x \, (Concept(x) \implies \text{AlreadyPresent}(x))$ が機械的に導出された。 $\blacksquare$
T7（絶対的無の成立不能定理 — 第6章） 成立根拠：定義 D2e と定義スキーマ D1c・定義 D1b の組み合わせ（背理法）
⊢  ¬∃x  AbsoluteNothing(x)
【定理の意味】絶対的無（AbsoluteNothing）を満たす個体 x は原理的に存在し得ない。
[LaTeX] $$\vdash \neg \exists x \, \text{AbsoluteNothing}(x)$$
【形式的証明（Mechanical Derivation）】
  1. $\exists x \, \text{AbsoluteNothing}(x)$ と仮定し（背理法の仮定）、存在例化によりある個体定数 $a$ について $\text{AbsoluteNothing}(a)$ とする。
  2. 定義 D2e より、双条件除去と MP で $\mathbf{S}(\text{AbsoluteNothing}(a)) \land \neg B(a)$ を得る。
  3. ステップ2に連言除去（左項取り出し）を適用し、$\mathbf{S}(\text{AbsoluteNothing}(a))$ を得る。
  4. 定義スキーマ D1c（$\forall x \, (\mathbf{S}(\Phi(x)) \implies S(x))$）において単項述語 $\Phi := \text{AbsoluteNothing}$ と置くと、$\mathbf{S}(\text{AbsoluteNothing}(a)) \implies S(a)$。これとステップ3より MP で $S(a)$ を得る。
  5. 定義 D1b（$S(a) \implies B(a)$）とステップ4より、MP で $B(a)$ を得る。
  6. 一方、ステップ2に連言除去（右項取り出し）を適用すると $\neg B(a)$ が得られ、ステップ5の $B(a)$ と連言導入で結合すると明示的矛盾 $B(a) \land \neg B(a)$（$\bot$）が導出される。
  7. よって背理法（否定導入）により、$\vdash \neg \exists x \, \text{AbsoluteNothing}(x)$ が機械的に導出された。 $\blacksquare$

Ⅶ. 想定される外部批判・疑問への論理的回答（FAQ）

本体系に対して外部の視点（一般的な二元論や既存の論理学・科学哲学の枠組み）から投げかけられやすい代表的な疑問について、内部規則に基づく論理的回答を以下に明記する。

Q1. 「対象を認識する行為が観念であること（A1）」から「対象そのものが観念であること（T2）」を導くのは、認識論と存在論の混同（循環論法）ではないか？

回答：
「認識作用」と「対象そのもの（物自体）」を分けなければならないという主張自体が、未証明の外部前提（カント的・近代的な主客二元論）に依存している。本体系のT1が示す通り、「観念（認識）の外側に独立した別の存在領域がある」という仮定自体が観念 𝐒 の内部から一歩も出られない以上、構造的に自己矛盾を起こして空集合となる。また本書における観念は「脳内の主観的イメージ（幻）」ではなく、対象（物質・肉体）も認識も同格に含む実在の原理（T3）であるため、物質の実在性が損なわれることはない。

Q2. 「主客や自他の区分は便宜（D2）であり単一座標で一つである」としながら、前文や終章で「人間それぞれの境界を守るべきだ」と主張するのは内部矛盾ではないか？

回答：
全く矛盾しない。「便宜 F」とは「無価値な幻」という意味ではなく、「単一座標 c₀ 上の全体が、人間や個別の世界として具体的に成立するための不可欠な構造規則」である。そしてT3により、各人が生きる個別の世界（便宜によって形作られた喜びや愛着の領域）もまた、物理学の法則や宇宙全体と1ミリも劣ることなく100%同格の「原理的存在（実在）」として肯定される。存在に上下の優劣がない（上位の客観的真理から下位の主観を否定できない）からこそ、外部の尺度で他者の境界を踏み荒らし否定する行為は論理的に不当となる。

Q3. 公理A4（相互成立の対称性）や定義D5（存在＝意味）は、演繹されたものではなく著者が置いた独立の前提（再定義）ではないか？

回答：
その通りである。いかなる数学や論理学の体系も、無から定理を生むことはできず、体系の性格を決定づける「基本公理」と「定義」を出発点として置く。従来の哲学が「主客の非対称性（二元論）」や「存在と意味の分離（虚無主義の温床）」を暗黙の公理として採用し、結果として「心身問題」や「生の無意味さ」という解決不能なバグを抱え込んだのに対し、本書は「相互成立（A4）」と「存在＝意味（D5）」を明示的な公理・定義として選択することで、それらの擬似問題をすべて解消し無矛盾に閉じるモデルを構築している。

Q4. 「すべての概念が予め存在する（T6）」なら、人間が新しく何かを思いつくという経験（新規性）が説明できないのではないか？

回答：
「新しく生まれたかのように見える」のは、人間が便宜的時系列（Ftime：過去から未来への流れ）の枠組みを通して現象を捉えているためである。原理的座標 c₀ においては、無から有が生じる（Gen）のではなく、最初から全体構造の中に含まれている概念 x と人間 a との相互成立（P(a, x) ⇔ P(x, a)）が連続性 C(c₀, c₀) の中で現前している。これは数学において「新しい定理が発明されるのではなく、最初から論理空間に存在していた定理が発見される」のと全く同じ構造である。

Q5. 定理T7は「思考対象としての無」が有になることを示しただけで、「思考も認識もされない絶対的無」の不可能性までは否定できていないのではないか？

回答：
「思考も認識もされないが、観念の外部に実在する絶対的無」という想定は、定理T1（観念の原理的外部 Ext原理的 の自己崩落）によってすでに棄却されている。言語や思考を用いて「思考の外にある無」を主張した瞬間にそれは観念の内部の措定（𝐒）となり、一切措定されないものは体系の内外を問わず議論の対象（命題）として成立しないため、どの道を通っても「絶対的無」が成立する余地は存在しない。
