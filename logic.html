0. 本データの目的と位置づけ（参照前の前提条件）

本ページに掲載する形式論理体系（記号・定義・公理・定理）は、『世界の証明』の本文における主張に「論理的飛躍」「定義の混同」「暗黙の前提の密輸」が存在しないことを客観的に検算・可視化するための補助的な論理検証データ（仕様書）である。
本データの参照および批評にあたっては、以下の前提と方法論を厳密に共有するものとする。

■ 本論理式の適用範囲に関する3つの免責事項

1. 数式による世界の還元を目的としたものではない 本書の本質は、平易な日常言語によって個人と世界の実在およびその境界を守り切ることにあり、本ページの論理式が「数式そのものとして世界のすべてを説明している」と主張するものではない。あくまで本文の自然言語による推論に論理的飛躍がないことを検算するための補助ツールである。
2. 外部前提（主客二元論・直線的時間モデル）の排除 一般的な述語論理を素朴に適用すると、「認識の外部に客観的個体があらかじめ存在する」「時間は数直線上の前後関係である」という外部の前提が無自覚に混入する。本モデルでは、本書の内部規則（観念の根源性、枠組みの便宜化、相互成立の対称性、単一座標の連続性）のみを原始規則として忠実に定式化している。
3. 検証の範囲（無矛盾性と演繹的閉包の確認） 本モデルが示すのは、「第1章・第2章の初期定義（入口）および基本公理を採用したとき、外部の追加前提を一切必要とせず、第3章（観念＝存在）および第4章〜第6章（無始無終・全概念の予在・無の否定）を経て終章（存在＝意味）に至るまで、純粋な演繹として無矛盾に閉じている（Trivially Consistent）」という構造的事実である。

Ⅱ. 定義群（Definitions）

本文および付録において、語の意味を規定する内部規則。

D1（観念と現前の定義） 対応箇所：本文 第2章（p.37–38）・第3章（p.40）

理解・納得・認識・措定など、何かが「在る」「そうである」として成立する働きは、すべて「そう思う」という観念の成立である。

φ が成立・現前する  :=  𝐒(φ)
【読み方】ある事象や命題 φ が成立し目の前に現れているとは、それが「そう思う（観念 𝐒(φ)）」として成立していることと定義する。
[LaTeX] $$\phi ext{ が成立・現前する} := \mathbf{S}(\phi)$$
D2（便宜的枠組みの定義） 対応箇所：本文 第1章（p.32–34）・前文・詩「境界」

「主観と客観」「精神と物質」「認識と存在」「過去・現在・未来（時系列 Ftime）」および「自他の境界」といった区分は、世界を捉え人間が個として成立するために観念の内部で設定された便宜的枠組みである。

F(φ)  :=  φ は 𝒮（観念）の内部で設定された構造上の分割規則（便宜）である
【読み方】枠組み F(φ) とは、観念の外側にある絶対的な壁ではなく、観念 𝒮 の内部で世界を切り取り人間が存在するために設けられた構造規則（便宜）である。
[LaTeX] $$F(\phi) := \phi ext{ は }\mathcal{S} ext{ の内部で設定された構造上の分割規則である}$$
D3（原理的存在の定義） 対応箇所：本文 第3章（p.40）・終章（p.53）・付録『重要な点』

便宜的枠組み F による主客の上下や時系列の従属を取り払ったとき、他の存在の容器や影としてではなく、それ自体として成立している存在を「原理的存在（PE）」とする。

PE(x)  :=  𝐒(x) において上下・主従の隔たりなくそれ自体として成立していること
【読み方】x が「原理的存在（PE）」であるとは、何かの二次的な派生物や借り物としてではなく、観念の場において対等・同格の実在として成立していることをいう。
[LaTeX] $$PE(x) := \mathbf{S}(x) ext{ において上下・主従の隔たりなくそれ自体として成立していること}$$
D4（共在と予在の非時間的定義） 対応箇所：本文 第5章（p.47）・第6章（p.49–50）・終章（p.53）・付録

時系列 Ftime を前提としない原理的領域において、「同時（CoPresent）」と「予め存在する（AlreadyPresent）」を次のように定義する（Gen(x) は「無からの新規生成」を表す）。

CoPresent(x, y)  :=  ( Loc(x) = Loc(y) = c₀ )
AlreadyPresent(x)  :=  ( Loc(x) = c₀ ) ∧ PE(x) ∧ ¬Gen(x)
【読み方】「共在（同時）」とは同じ単一座標 c₀ 上にあること。「予め存在する（予在）」とは、時間的に昔にあったという意味ではなく、単一座標 c₀ 上で原理的存在として「無からの生成（始まり）を必要とせずに」存在していることをいう。
[LaTeX] $$ ext{CoPresent}(x, y) := (Loc(x) = Loc(y) = c_0)$$ $$ ext{AlreadyPresent}(x) := (Loc(x) = c_0) \land PE(x) \land eg Gen(x)$$
D5（真理と意味の定義） 対応箇所：前文（p.5, p.25）・終章（p.53–54）

真理とは固定された外部命題ではなく、追求によって観念として現前する事象そのものである。また、意味とは外部の目的から付与されるものではなく、存在そのものである。

Truth(x)  :=  追求の作用において 𝐒(x) が現前すること
M(x)  :=  B(x)
【読み方】「真理」とは追求されることによって現前するひとつの事象（𝐒(x)）であり、「意味（M(x)）」とは「存在すること（B(x)）」そのものである。
[LaTeX] $$Truth(x) := ext{追求の作用において }\mathbf{S}(x) ext{ が現前すること}$$ $$M(x) := B(x)$$

Ⅲ. 公理群（Axioms）

本体系の出発点および構造的規則として採用される基本前提。

A1（観念包摂公理） 対応箇所：本文 第1章（p.32–33）・第3章（p.39–40）

いかなる対象や命題 φ であれ、それを措定・認識・説明する行為は必ず観念 𝐒 を介してその内部で成立する。

∀φ  ( φ ⇒ 𝐒(φ) )
【読み方】すべての事象・対象・命題 φ について、φ が措定・議論されるならば、それは必ず観念 𝐒(φ) として成立している。
[LaTeX] $$ orall \phi \, (\phi \implies \mathbf{S}(\phi))$$
A2（枠組み内部性公理） 対応箇所：本文 第1章（p.32–34）

「客観的事実」や「物質」を含むいかなる便宜的枠組み F も、観念の外部にあるのではなく、観念の作用として成立する。

∀φ  ( F(φ) ⇒ 𝐒(φ) )
【読み方】すべての便宜的枠組み φ について、それが枠組み F(φ) であるならば、それは観念 𝐒(φ) の内部の働きとして成立している。
[LaTeX] $$ orall \phi \, (F(\phi) \implies \mathbf{S}(\phi))$$
A3（自律体系・多重説明公理） 対応箇所：本文 第1章（p.34）・付録『論考の前提・証明の定義・方法論について』

本体系の内部概念に外部体系の定義 Dext を適用してはならない。また、内部で無矛盾に閉じた説明体系 L は複数存在しうる。

( Dext(x) ⇏ Dint(x) )  ∧  ∃L₁, L₂ … ( Consistent(Li) )
【読み方】外部体系の定義（Dext）は本体系の内部定義（Dint）を規定しない。また、無矛盾に閉じた説明モデル（Li）は複数成立しうる（説明になってさえいれば答えは何通りあってもよい）。
[LaTeX] $$(D_{ ext{ext}}(x) ot\Rightarrow D_{ ext{int}}(x)) \land \exists L_1, L_2 \dots ( ext{Consistent}(L_i))$$
A4（相互成立の対称性公理） 対応箇所：本文 第4章（p.42）・第5章（p.45–47）

「ある対象を思い描く行為」と「ある対象によって思い描かれる行為」は原理的に同等であり、作用する側とされる側の間に一方向の従属関係はない。

∀x, y  ( P(x, y) ⇔ P(y, x) )
【読み方】すべての存在 x と y について、「x が y を思い描くこと」と「y によって x が思い描かれること」は完全に同等（双方向的）である。
[LaTeX] $$ orall x, y \, (P(x, y) \iff P(y, x))$$
A5（単一座標と連続性の公理） 対応箇所：本文 第5章（p.45–47）

原理的には時系列（前後関係による別座標）は存在せず、すべての原理的存在は唯一の同一座標点 c₀ 上で展開され、「今が今をもたらし続ける」連続性 C(c₀, c₀) のみがある。

∀x  ( PE(x) ⇒ Loc(x) = c₀ )  ∧  C(c₀, c₀)
【読み方】すべての原理的存在 x は唯一の同一座標点 c₀ 上に位置し、そこには「今が今をもたらし続ける連続性 C(c₀, c₀)」が展開されている。
[LaTeX] $$ orall x \, (PE(x) \implies Loc(x) = c_0) \land C(c_0, c_0)$$
A6（全体作用による個体制約公理） 対応箇所：本文 第5章【補足】（p.48）

個人の思考（個別観念 Sind）も実在の一部であるが、単一座標 c₀ 上ではすべての観念が同時に相互成立（共在）して作用するため、一個人の観念のみによって世界全体を恣意的に変更することはできない。

∀x  ( CoPresent(Sind, Sx) ⇒ Limited(Sind) )
【読み方】「私」という観念だけでなく、人類・宇宙・他者を愛する観念などあらゆる観念 Sx が同一座標上で同時に現象し影響し合っているため、個人に許された裁量（Sind）は限定される（空想だけで直ちに鳥に変身したりしない理由）。
[LaTeX] $$ orall x \, ( ext{CoPresent}(S_{ ext{ind}}, S_x) \implies ext{Limited}(S_{ ext{ind}}))$$

Ⅳ. 定理群（Theorems：演繹の連鎖）

公理 A1〜A6 と定義 D1〜D5 から、外部の追加前提なしで導出される命題群。

【第1段階：認識と存在の統合（第1章〜第3章）】
T1（外部実在仮説の自己崩落） 導出根拠：D1, D2, A1, A2

「観念の外部に独立した客観的物質 x が存在する（B(x) ∧ Ext(x)）」という仮説自体が、A1・A2により観念の内部作用 𝐒(B(x) ∧ Ext(x)) としてしか成立しない。ゆえに、「観念の原理的外部（Ext原理的）」という領域は構造的自己矛盾により空集合となる。

⊢  ¬∃x  ( B(x) ∧ Ext原理的(x) )
【読み方】公理より、「観念の原理的な外側（Ext原理的）に独立して存在する x」なるものは一切存在しないことが証明される（想定した瞬間に観念内部の枠組みとなるため）。
[LaTeX] $$ dash eg \exists x \, (B(x) \land Ext_{ ext{原理的}}(x))$$
T2（観念存在定理 — 第3章の中心命題） 導出根拠：A1, T1（本文 第3章 p.40 → 終章 p.52）

A1により B(x) ⇒ 𝐒(B(x))。T1により、観念 𝐒（認識・主観）と「外的な存在 B」の間に原理的な上下・主従の隔たりが存在しないため、𝐒(B(x)) と S(x) は論理的に同値となる。ゆえに、あらゆる存在は観念そのものであり、すべての観念は実在する。

⊢  ∀x  ( B(x) ⇔ S(x) )
【読み方】すべての x について、「x が存在する（実在する）」ことと「x が観念そのものである」ことは論理的に同値である（私たちと世界は同等の存在である）。
[LaTeX] $$ dash orall x \, (B(x) \iff S(x))$$
【第2段階：対象と像の同格化（第4章・第5章）】
T3（全存在の原理的同格性） 導出根拠：D3, A4, T2（本文 第4章 p.42・第5章 p.47・付録『重要な点』）

T2およびA4（P(x, y) ⇔ P(y, x)）により、肉体と魂、物質と精神、対象とその像の間に「どちらが上位の本物でどちらが下位の派生か」という存在論的格差は存在せず、すべてが原理的存在として同格に実在する。

⊢  ∀x  ( B(x) ⇒ PE(x) )
【読み方】すべての存在する x は、何かの借り物や幻ではなく、上下・主従のない「原理的存在（PE）」そのものとして実在する。
[LaTeX] $$ dash orall x \, (B(x) \implies PE(x))$$
【第3段階：無の消去と無始無終の導出（第5章〜第6章）】
T4（無からの一方的生成の否定） 導出根拠：A4, T2（本文 第5章 p.45–47・第6章 p.49）

もしある概念 x が無から主体 a によって一方的に生成された（Gen(x)）と仮定すると、生成の起点で a → x の一方向作用しかなく、A4（P(a, x) ⇔ P(x, a)）に反する。ゆえに、いかなる概念も無から一方的に生成されたものではない。

⊢  ∀x  ( B(x) ⇒ ¬Gen(x) )
【読み方】すべての存在する x は、何もない状態（無）から一方的に新規生成されたものではない（互いが互いをもたらし合う関係にある）。
[LaTeX] $$ dash orall x \, (B(x) \implies eg Gen(x))$$
T5（単一座標における無境界性＝無始無終） 導出根拠：A5, T3（本文 第5章 p.45–47・終章 p.52）

A5により、すべての存在が位置する原理的座標は c₀ ただ一つであり、その外側に「始まる前の座標 cbefore」や「終わった後の座標 cafter」は存在しない。外側の座標が存在しないため、世界の始まり（Begin）と終わり（End）は同時に不成立となる。

⊢  ∀x  ( PE(x) ⇒ ¬Begin(x) ∧ ¬End(x) )
⊢  ¬Begin(World) ∧ ¬End(World)
【読み方】すべての原理的存在 x（およびこの世界 World）には、始まりも終わりも存在しない。
[LaTeX] $$ dash orall x \, (PE(x) \implies eg Begin(x) \land eg End(x))$$ $$ dash eg Begin(World) \land eg End(World)$$
T6（全概念の予在定理 — 第6章） 導出根拠：D4, A5, T3, T4（本文 第6章 p.49–50）

A5（Loc(x)=c₀）、T3（PE(x)）、T4（¬Gen(x)）を結合し、D4を適用すると、人間が便宜的時系列の中で「新しく思いついた」と認識するあらゆる概念も、原理的には単一座標 c₀ 上に生成なしで予め存在している。

⊢  ∀x  ( Concept(x) ⇒ AlreadyPresent(x) )
【読み方】すべての概念 x は、始まりや前提を必要とせず、原理的存在として単一座標上に「予め存在している（AlreadyPresent）」。
[LaTeX] $$ dash orall x \, (Concept(x) \implies ext{AlreadyPresent}(x))$$
T7（絶対的無の成立不能定理 — 第6章） 導出根拠：A1, T1, T2, T5（本文 第6章 p.49–50）

T5により単一座標 c₀ の外部に「無の領域」は存在しない。さらにA1・T2により、いかなる形であれ「絶対的無（∅abs）」を措定・想定した瞬間に、それは 𝐒(∅abs) すなわち「無という観念（有 B(∅abs)）」として実在してしまう。また「措定も認識もされない外部の無」という仮定自体がT1により自己崩落するため、絶対的無は原理的に成立し得ない。

⊢  𝐒(∅abs) ⇒ B(∅abs) ⇒ ¬AbsoluteNothing(∅abs)
【読み方】「絶対的な無（∅abs）」を想定した時点で、それは「無という概念の実在（B）」となるため、真の意味での「絶対的無（虚無）」は原理的に成立し得ない。
[LaTeX] $$ dash \mathbf{S}( arnothing_{ ext{abs}}) \implies B( arnothing_{ ext{abs}}) \implies eg ext{AbsoluteNothing}( arnothing_{ ext{abs}})$$
【第4段階：存在と意味の結合（終章）】
T8（世界の肯定と意味の充足 — 終章の結論） 導出根拠：D5, T2, T3, T5（本文 終章 p.52–55・詩「境界」 p.58–61）

T2・T3・T5により、すべての存在（物理学の法則も、個人の喜びや愛着も）は欠けることなく無始無終の原理的存在として同格に実在しており、D5（M(x) := B(x)）により、存在していること自体がそのまま意味の完全な充足である。外部の尺度や目的に照らして存在の価値を否定する根拠は原理的に存在しない。

⊢  ∀x  ( S(x) ⇔ B(x) ⇔ PE(x) ⇔ M(x) )
【読み方】すべての x について、「観念であること（S）」「存在すること（B）」「原理的存在であること（PE）」「意味そのものであること（M）」は完全に同値であり、誰の存在も価値観も否定されない。
[LaTeX] $$ dash orall x \, (S(x) \iff B(x) \iff PE(x) \iff M(x))$$

Ⅵ. 想定される外部批判・疑問への論理的回答（FAQ）

本体系に対して外部の視点（一般的な二元論や既存の論理学・科学哲学の枠組み）から投げかけられやすい代表的な疑問について、内部規則に基づく論理的回答を以下に明記する。

Q1. 「対象を認識する行為が観念であること（A1）」から「対象そのものが観念であること（T2）」を導くのは、認識論と存在論の混同（循環論法）ではないか？

回答：
「認識作用」と「対象そのもの（物自体）」を分けなければならないという主張自体が、未証明の外部前提（カント的・近代的な主客二元論）に依存している。本体系のT1が示す通り、「観念とは独立した外部の対象そのもの」を措定する行為自体が観念 𝐒 の内部から一歩も出られない以上、「観念（認識）の外側に独立した別の存在領域がある」という仮定は構造的に余剰（空集合）となる。また本書における観念は「脳内の主観的イメージ（幻）」ではなく、対象（物質・肉体）も認識も同格に含む実在の原理（T3）であるため、物質の実在性が損なわれることはない。

Q2. 「主客や自他の区分は便宜（D2）であり単一座標で一つである」としながら、前文や終章で「人間それぞれの境界を守るべきだ」と主張するのは内部矛盾ではないか？

回答：
全く矛盾しない。「便宜 F」とは「無価値な幻」という意味ではなく、「単一座標 c₀ 上の全体が、人間や個別の世界として具体的に成立するための不可欠な構造規則」である。そしてT3により、各人が生きる個別の世界（便宜によって形作られた喜びや愛着の領域）もまた、物理学の法則や宇宙全体と1ミリも劣ることなく100%同格の「原理的存在（実在）」として肯定される。存在に上下の優劣がない（上位の客観的真理から下位の主観を否定できない）からこそ、外部の尺度で他者の境界を踏み荒らし否定する行為は論理的に不当となる。

Q3. 公理A4（相互成立の対称性）や定義D5（存在＝意味）は、演繹されたものではなく著者が置いた独立の前提（再定義）ではないか？

回答：
その通りである。いかなる数学や論理学の体系も、無から定理を生むことはできず、体系の性格を決定づける「基本公理」と「定義」を出発点として置く。従来の哲学が「主客の非対称性（二元論）」や「存在と意味の分離（虚無主義の温床）」を暗黙の公理として採用し、結果として「心身問題」や「生の無意味さ」という解決不能なバグを抱え込んだのに対し、本書は「相互成立（A4）」と「存在＝意味（D5）」を明示的な公理・定義として選択することで、それらの擬似問題をすべて解消し無矛盾に閉じるモデルを構築している。

Q4. 「すべての概念が予め存在する（T6）」なら、人間が新しく何かを思いつくという経験（新規性）が説明できないのではないか？

回答：
「新しく生まれたかのように見える」のは、人間が便宜的時系列（Ftime：過去から未来への流れ）の枠組みを通して現象を捉えているためである。原理的座標 c₀ においては、無から有が生じる（Gen）のではなく、最初から全体構造の中に含まれている概念 x と人間 a との相互成立（P(a, x) ⇔ P(x, a)）が連続性 C(c₀, c₀) の中で現前している。これは数学において「新しい定理が発明されるのではなく、最初から論理空間に存在していた定理が発見される」のと全く同じ構造である。

Q5. 定理T7は「思考対象としての無」が有になることを示しただけで、「思考も認識もされない絶対的無」の不可能性までは否定できていないのではないか？

回答：
「思考も認識もされないが、観念の外部に実在する絶対的無」という想定は、定理T1（観念の原理的外部 Ext原理的 の自己崩落）によってすでに棄却されている。言語や思考を用いて「思考の外にある無」を主張した瞬間にそれは観念の内部の措定（𝐒）となり、一切措定されないものは体系の内外を問わず議論の対象（命題）として成立しないため、どの道を通っても「絶対的無」が成立する余地は存在しない。
