Formal logic model and machine verification in Lean 4 (2026)

https://doi.org/10.5281/zenodo.24368376

The argument of this book was complete when it was published in 2022 (the original was archived at the National Diet Library of Japan on publication).

In 2026 the argument was written out as a formal logic model (a system of definitions and axioms). In that model it is proved that the book’s main conclusions follow from its premises without any logical gap, and that the premises do not contradict one another (consistency); every one of these proofs has passed machine verification in the proof assistant Lean 4.

The verification was carried out not by AI but by Lean 4, and anyone can repeat it. The model was made with the help of AI. Naturally, however, whether the model exists or not does not change the structural value of the book Proof of a World itself: AI and Lean 4 are no more than auxiliary tools that presuppose the original text. For details, including how each formula corresponds to the text, see the link.

What was checked in Lean 4

The derivations in Section IV and the model in Section VI of the formal model (Rev. 5) have been checked mechanically with the proof assistant Lean 4.
  • What was checked: (1) that Lemma L1 and Theorems T1–T8 with their corollaries are derivable from Definitions D1–D5 and Axioms A1, A2, A4–A8, in a general form that holds for any number of beings; (2) that the model ℳ of Section VI satisfies all 19 formulas of the definitions and axioms (consistency); (3) that the definitions and axioms do not force all beings to be numerically one (non-triviality; in ℳ the individual and the world are distinct).
  • Result (19 November 2026, Lean v4.36.0, Lean Web): no errors, no warnings, and no unproved steps (sorry). Lean’s report of what each result depends on (#print axioms) shows that no result uses any premise beyond the definitions and axioms, except the version of the corollary of T6 derived as in the text (by double-negation elimination), which uses the standard axioms of classical logic (propext, Classical.choice, Quot.sound). The same corollary is also derived by a route that does not use double-negation elimination (the note to A8).
  • Notes on the encoding: the schemas (A1, A2, A8, D5a) are written in Lean as single statements about all propositions, which is slightly stronger than a schema. The derivations use only instances expressible in the language ℒ, and the model ℳ satisfies even the stronger form, so both conclusions also hold for the schemas. A3, a meta-theoretic restriction, is not written in Lean.
  • Scope: Lean checks only what lies inside the formal system (derivability and consistency). Whether the formulas faithfully represent the book, and whether the premises (axioms) are true, lie outside its scope.
  • Record (DOI): this formal model (Rev. 5) and its machine verification in Lean 4 are archived on Zenodo, together with the document in Japanese and in English (PDF) and the Lean file (https://doi.org/10.5281/zenodo.24368376).
  • File and how to re-run the check: ProofOfAWorld_Rev5.lean (view on GitHub). Opening Re-run the check on Lean Web loads this file into the official browser version of Lean, so that anyone can repeat the same check.

How to re-run the check

  1. Press “Re-run the check on Lean Web” above. The official browser version of Lean (live.lean-lang.org) opens with this file loaded.
  2. Wait a moment until loading and checking are finished.
  3. Check that “All Messages” on the right shows the 19 results of #print axioms, with no errors and no warnings.

How to read the result

  • No red error and no warning anywhere → every proof was accepted.
  • “does not depend on any axioms” → the result follows from the definitions and axioms of the formal model by logic alone; nothing else was assumed.
  • One result, T6_cor_text_route (the route of the text, which uses double-negation elimination), relies on classical logic; Lean then lists its three standard axioms propext, Classical.choice, Quot.sound. This is expected.
  • If any line lists any other axiom, that proof did not pass.
